Today's release includes the following updates:
<span class="tag-bugfix">bugfix</span>

- Enforces that a patient's sex at birth is set to male or female when sending a controlled substance prescription. This is required downstream when sending controlled substance requests and was causing silent failures.
- Fixed display issues on Lab Review, Imaging, and Referral templates when a patient's sex at birth is not set to male or female. The display now shows as "Other" or "Unknown" rather than defaulting to female.
- Fixed compatibility with plugins that look up chart commands by their manifest schema_key. Plugin custom commands installed after release 1.312.0 were stored with an internal version suffix on chart command rows and note bodies, breaking plugin code that filtered by the bare schema_key. Existing chart entries are migrated back to the bare key automatically on deploy.

<span class="tag-sdk">sdk</span>

- PluginCommand schema_keys are now unique across all installed plugins. Installing a plugin whose manifest declares a schema_key already owned by another installed plugin now fails with a clear validation error instead of silently overwriting the existing command.
- Fixed remaining versioned schema keys as a follow-up to undoing versioned plugin commands.
