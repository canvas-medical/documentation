Today's release includes the following updates:

<span class="tag-bugfix">bugfix</span>

- Added the `FAX_EVENT_HISTORY` item to the [`PatientNoteHeaderDropdownConfiguration`](/sdk/layout-effect/#patient-note-header-dropdown-configuration) effect, allowing plugins to include fax event history in the note header dropdown menu.

<span class="tag-sdk">sdk</span>

- The [`ImagingOrderCommand`](/sdk/commands/#imagingorder) and [`ReferCommand`](/sdk/commands/#refer) now support [`delegate()`](/sdk/commands/#delegate) and [`sign()`](/sdk/commands/#sign) methods, enabling plugins to programmatically delegate and sign these commands as part of automated workflows.
