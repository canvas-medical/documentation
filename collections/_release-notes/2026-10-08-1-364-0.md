Today's release includes the following updates:
<span class="tag-bugfix">bugfix</span>

- Fixed an issue where Appointment note actions for plugin-created and plugin-updated notes were attributed to the booked provider instead of the acting user.

<span class="tag-sdk">sdk</span>

- SDK plugin applications can now appear in the provider menu and search panel bar, showing conditionally based on the current user, patient, and page. These entries support custom icons, badge counts, and menu placement.
- Diagnosis search now includes the [FY2027 ICD-10-CM codes](/product-updates/icd-updates/#icd-10-cm-2027) that take effect October 1, 2026: 190 new codes and 4 updated descriptions. The 30 codes that CMS retired are now end-dated.
- Internal CI change: automated browser test runs stop sending errors to Canvas's production error monitoring. No change for users.
