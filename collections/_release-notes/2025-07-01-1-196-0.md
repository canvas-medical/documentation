Today’s release includes the following updates:
- Adds an effect that allows plugins to create a PatientExternalIdentifier for an existing patient. Requires patient_id, system (the external partner’s URL), and value (the external ID). [Read more.](/sdk/effect-create-patient-external-identifier/)
- Adds claims and transactions to the data module. [Read more.](/sdk/data-claim/)
- Enables protocol cards created via plugins to be snoozed. [Read more.](/sdk/effect-protocol-cards/)
- Fixes a bug that prevented plugins from setting a medication sig.
- Adds an effect to automatically create a PatientExternalIdentifier when a new patient is created. [Read more.](/sdk/effect-patient/#patientexternalidentifier)
- Exposes pharmacy search functionality to plugins. [Read more.](/sdk/utils/#making-requests-to-the-pharmacy-service)
