Today’s release includes the following updates:
- Adds an effect that allows plugins to create a PatientExternalIdentifier for an existing patient. Requires patient_id, system (the external partner’s URL), and value (the external ID).
- Adds claims and transactions to the data module.
- Enables protocol cards created via plugins to be snoozed.
- Fixes a bug that prevented plugins from setting a medication sig.
- Adds an effect to automatically create a PatientExternalIdentifier when a new patient is created.
- Exposes pharmacy search functionality to plugins.
