---
title: Adds Option to Install Plugins in Disabled State via Admin UI
layout: productupdates
tags: plugins sdk
date: 2026-05-04
---

The plugin upload page in the Admin UI now includes an "Is enabled" checkbox. When unchecked, plugins are installed in a disabled state—the package uploads but handlers do not run until the plugin is enabled from the Plugins admin page. The checkbox is checked by default, preserving existing behavior where plugins are enabled immediately on install.
