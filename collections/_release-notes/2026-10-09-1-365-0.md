Today's release includes the following updates:
<span class="tag-bugfix">bugfix</span>

- Fixed an issue where Staff password reset links were returned as invalid.
- Patient statements no longer split a visit's services and amounts onto a separate page from its date of service and provider.
- Patient portal users can open only portal menu applications. Staff-only applications do not run for patients.

<span class="tag-sdk">sdk</span>

- Plugins can now make an enabled patient portal menu application the portal's default home page. Patients who open the portal are sent straight to that application. If no valid application is set, they see the standard widgets landing page.
- Plugins can now read invoice PDFs, business line logos, imaging order PDFs, uncategorized clinical document files, letter attachment PDFs, and integration task documents through the SDK data models, each with a presigned URL property.
