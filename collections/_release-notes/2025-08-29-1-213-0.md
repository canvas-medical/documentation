Today's release includes the following updates:
- **Update staff profile license entry**<br/>
In admin, the following new fields were added to staff profile licenses: license type, state, and primary. The new staff license fields are available in [FHIR Practitioner](https://docs.canvasmedical.com/api/practitioner/). This change is backwards compatible. [Read more](https://canvas-medical.help.usepylon.com/articles/4283873790-add-a-new-staff-member#staff-license-25).
