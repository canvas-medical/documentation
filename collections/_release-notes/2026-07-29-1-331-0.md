Today's release includes the following updates:
<span class="tag-bugfix">bugfix</span>

- Commands marked "entered in error" no longer appear on Print Note or the Generate Full Chart PDF; they remain in the audit-trail PDF stamped to the note footer at lock time.
- Plugins can now block the Create Coding Gap, Validate Coding Gap, Assess Coding Gap, Defer Coding Gap, and Change Medication commands at commit time by returning a validation error from a `{COMMAND}__POST_VALIDATION` handler.

<span class="tag-sdk">sdk</span>

- Fixed a crash that could take down the entire patient chart when opening a note whose type version had not yet loaded; the affected note now shows a contained error message instead.
- Uncategorized clinical document reviews can now be delegated to another staff member or team, with instructions and optional consent to apply the original reviewer's signature, and routed back to the original reviewer.
- Long entries in "Reviewed:" sections (e.g., medications, conditions, allergies) on a printed or PDF note now wrap to the next line instead of being clipped at the right edge of the page.
- Control Room is now the single source of truth for the variables (secrets) of Control Room–managed plugins, and can add, update, and remove them in one declared set. Changing or uninstalling a Control Room–managed plugin from the CLI is now blocked with a clear error, so local changes can't silently override a managed deployment.
- Providers who hold more than one clinical role now consistently display their highest-privilege role and its credential abbreviation, instead of an arbitrarily chosen one.
- Change Medication command records are now available to plugin developers through the SDK data layer via a new stable identifier. Long annotations in command autocomplete dropdowns are now truncated with an ellipsis and reveal their full text on hover.
- Request/response logging now skips the health-probe endpoints (`/healthcheck` and `/host-information/`), redacts query-string parameter values from logged URLs, and no longer stores a duplicate copy of the request body on the response record, reducing Elasticsearch log volume and tightening what is written to logs.
- Upgraded the moment / moment-timezone JavaScript libraries to patch two security advisories (CVE-2022-24785, CVE-2022-31129) and refresh bundled timezone data to 2025b.
