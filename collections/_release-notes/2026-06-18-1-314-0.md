Today's release includes the following updates:
<span class="tag-sdk">sdk</span>

- The SDK data module now exposes chart section review content and visual exam findings (title, narrative, and a viewable image URL), so plugins can reproduce these visit-summary sections as they appear in Canvas.
- The SDK data module now exposes registered custom command metadata (label, section, schema key) and Django content type IDs, so plugins can read back [custom command](/sdk/commands-custom-command/) display details and work with generic relations and permalinks.
