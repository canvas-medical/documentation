Today's release includes the following updates:

<span class="tag-ui">ui</span>

- The Data Integration fax list can now be filtered by inbound number, for practices receiving faxes on multiple numbers.

<span class="tag-sdk">sdk</span>

- Plugins can now read [`StaffMetadata`](/sdk/data-staff/#staffmetadata) from the SDK data module, and write to it with the new [`StaffMetadata`](/sdk/effect-staff-metadata/) effect.
- Plugins can now read [`StaffExternalIdentifier`](/sdk/data-staff/#staffexternalidentifier) from the SDK data module, and write to it with the new [`CreateStaffExternalIdentifier`](/sdk/effect-staff-external-identifier/) effect.
- Plugin logs can now be filtered by plugin and handler in both the [admin UI](/sdk/plugin-logs/#plugin-logs-in-the-admin-ui) and the [`canvas logs` CLI](/sdk/canvas_cli/#canvas-logs) (`--plugin`, `--handler`). _(CLI flags require Canvas CLI 0.150.0 or newer)_
- Plugins can now access [patient photos](/sdk/data-patient/#accessing-the-patient-photo) directly from the SDK.
- Plugins can now request clipboard read and write access for their iframes via the new [`CLIPBOARD_READ` and `CLIPBOARD_WRITE`](/sdk/layout-effect/#additional-configuration) permissions in `CANVAS_MANIFEST.json`. _(requires Canvas CLI 0.151.0 or newer)_
- The [consent template document](/sdk/data-patient-consent/#accessing-document-files) attached to a `PatientConsentCoding` is now readable from the SDK.
- Plugins can now manage documents in the [Data Integration queue](/sdk/effect-data-integration/) with a new set of SDK effects:
  - [`AssignDocumentReviewer`](/sdk/effect-data-integration/#assigning-a-reviewer) — assign a staff member or team as reviewer, with configurable review mode.
  - [`CategorizeDocument`](/sdk/effect-data-integration/#categorizing-a-document) — set a document's type (clinical or administrative).
  - [`JunkDocument`](/sdk/effect-data-integration/#marking-a-document-as-junk) — mark a document as junk.
  - [`LinkDocumentToPatient`](/sdk/effect-data-integration/#linking-a-document-to-a-patient) — link a document to a patient.
  - [`PrefillDocumentFields`](/sdk/effect-data-integration/#prefilling-document-fields) — prefill template field values on a document.
  - [`RemoveDocumentFromPatient`](/sdk/effect-data-integration/#removing-a-document-from-a-patient) — unlink a document from a patient.
- Fixed a bug where invoking `CreatePatientExternalIdentifier` effect would silently delete pre-existing unexpired identifiers on the same patient. Multiple invocations now correctly result in multiple external identifiers as expected.
