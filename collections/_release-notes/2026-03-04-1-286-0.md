Today's release includes the following updates:


<span class="tag-bugfix">bugfix</span>

- Questionnaires with long question names could become corrupted if used within the Questionnaire Builder. This corruption will no longer happen.
- The unsupported browser warning was hidden on Safari; it is now visible. Safari is not a supported browser for Canvas, you must use Chrome.

<span class="tag-api">api</span>

- Fixes Facility addresses not including country on FHIR's Patient read/search

<span class="tag-sdk">sdk</span>

- Adds Prescription to the SDK data module.
- Adds SDK events for Prescription status changes.
