Today's release includes the following update:

- Added support for new FHIR v2 granular scopes: https://hl7.org/fhir/smart-app-launch/STU2/scopes-and-launch-context.html#user-level-scopes
- Enabled support for initiating OAuth authorization code flow with an HTTP POST request
- Added `iss` and `sub` to OAuth token introspection response body
