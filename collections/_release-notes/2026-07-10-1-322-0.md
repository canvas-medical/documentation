Today's release includes the following updates:
<span class="tag-bugfix">bugfix</span>

- Fixed an error that prevented billing line items from saving when a charge's Fee Schedule (CDM) name exceeded 255 characters. Affected charges now save correctly using the charge's short name.
- Fixed an issue where lab orders that include open-choice Ask-at-Order-Entry questions could produce an error.
- Plugins subscribing to APPOINTMENT_METADATA_CREATED and APPOINTMENT_METADATA_UPDATED events now receive the associated appointment id and patient id in the event context, which was previously empty.
- Annotation chips shown next to command search results (for example coding-system labels like RxNorm) are now larger, higher-contrast, and rendered in a sans-serif font, making them easier to read — including for users with mildly reduced visual acuity.
