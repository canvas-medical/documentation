Today's release includes the following updates:

<span class="tag-bugfix">bugfix</span>

- Fixes a bug with the "assessments" field on the Referral SDK Data Model.

<span class="tag-sdk">sdk</span>

- Implements a new consolidated `ClaimEffect` with methods for adding a comment, posting a payment, adding labels, removing labels, and moving to a queue. Please note that the original standalone effects `AddClaimComment`, `PostClaimPayment`, `AddClaimLabel`, `RemoveClaimLabel`, and `MoveClaimToQueue` have been marked for deprecation and will be removed in an upcoming release. We recommend migrating to the new consolidated ClaimEffect [Read more.](/sdk/effect-claims)
