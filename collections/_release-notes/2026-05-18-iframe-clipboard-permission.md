---
title: IFrames can now request clipboard permissions
tags: sdk
layout: productupdates
date: 2026-05-18
---

If you launch iframes from a plugin, you can now request the `CLIPBOARD_READ`
and `CLIPBOARD_WRITE` browser permissions in your `CANVAS_MANIFEST.json` via
the `url_permissions` structure.

See [Additional Configuration to the LaunchModalEffect](/sdk/layout-effect/#additional-configuration) for more details.
