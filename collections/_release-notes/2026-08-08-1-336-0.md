Today's release includes the following updates:
<span class="tag-bugfix">bugfix</span>

- Fixed an issue where a failed real-time insurance eligibility check recorded a blank error message. It now records a meaningful error reason (such as the clearinghouse's HTTP status, e.g. "403 Forbidden: ClaimMD Server Error"), making it clearer why a verification didn't complete.
- Fixed an issue where a plugin-defined custom command could fail if it was originated shortly after its plugin was installed. Custom commands are now resolved on demand in every process, preventing those failures.
