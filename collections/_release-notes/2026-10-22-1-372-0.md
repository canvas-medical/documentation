Today's release includes the following updates:

<span class="tag-bugfix">bugfix</span>

- Fixed an issue where the return address on the patient statement payment stub printed too high for the return envelope window, cutting off the organization name. The return address now sits centered in the window.

<span class="tag-ui">ui</span>

- The Assess command has a **Show in problem list** checkbox, turned on by default. Turn it off to record the diagnosis as an encounter diagnosis for this visit instead of a problem list item. The choice is saved as the condition's category, which the [FHIR Condition](/api/condition/) resource returns as `encounter-diagnosis` or `problem-list-item`. In a later release, it will also control which conditions show in the patient summary.

- Hovering an application icon in the global panel or the patient chart panel shows the application's name in a tooltip. Application icons in the panel and the applications drawer also use the application's name as their alt text, so screen readers announce them by name.

<span class="tag-sdk">sdk</span>

- Plugins can write records that carry a file uploaded through a [SimpleAPI route that stores uploads](/sdk/handlers-simple-api-http/#storing-uploaded-files):
  - The new [Coverage](/sdk/effect-coverage/) effect creates, updates, expires, removes, and reorders a patient's insurance coverages, with front and back card images.
  - The new [Patient Identification Card](/sdk/effect-patient-identification-card/) effect creates, updates, and deletes a patient's identification cards, with an image.
  - The [Message](/sdk/effect-messages/#attaching-files) effect attaches PNG, JPEG, or PDF files.
  - The new [VisualExamFinding](/sdk/commands/#visualexamfinding) command adds a visual exam finding with an image.
- Plugins can set the Assess **Show in problem list** choice with `show_in_problem_list` on [`AssessCommand`](/sdk/commands/#assess), and read it from an Assess command's `data` in the [Command](/sdk/data-command/) data module.
- Plugins can link an [Order DME](/sdk/commands/#orderdme) command to an Assess in the same note with `assessment_id`. Linking adds the assessed condition's ICD-10 codes to the order. Read the link from the [DmeOrder](/sdk/data-dme/) `assessment` field, or from an assessment's `linked_dme_orders`.
- The [`CommandTypeSetting`](/sdk/data-command-type-setting/) data model lists only the command types available on an instance. Treat a command type with no row the same as one that is turned off.
