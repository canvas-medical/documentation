Today's release includes the following updates:
<span class="tag-bugfix">bugfix</span>

- Fixed an issue where the supervising provider dropdown on a Staff entry in the admin site displayed duplicate default choices. These choices are now deduplicated.

<span class="tag-sdk">sdk</span>

- An Add Condition [command](/sdk/commands/) is now available in the History section of the note. It records a coded (ICD-10) condition on the patient's Conditions list as active, without opening an assessment for that day. The command captures the condition, background, an approximate date of onset, and comments, and shows an informational message when the same condition is already on the patient's Conditions list. It uses the same condition picker as Diagnose. The command is available on every instance. A condition's background follows the most recent assessment of it, and assessing a condition prefills Background from the condition. Entering the last assessment in error restores the background the condition was recorded with.
- A Remove Past Medical History [command](/sdk/commands/) is now available in the note's History section, letting clinicians take a committed past medical history entry off a patient's chart and record why — without amending the note that originally added it. The command is available both in the note and to plugins via the SDK; entering the removal in error puts the entry back on the chart.
