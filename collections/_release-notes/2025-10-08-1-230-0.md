Today's release includes the following updates:

<span class="tag-sdk">sdk</span> 
 
- Updates UPDATE_APPOINTMENT / UPDATE_SCHEDULE_EVENT to now update existing records without creating a new appointment.
- Introduces new effects, RESCHEDULE_APPOINTMENT / RESCHEDULE_SCHEDULE_EVENT, that create new records with updated values and cancels originals (per existing behavior). [Read more.](sdk/effect-notes/#reschedule-appointment)
- Adds support for returning multiple effects from SDK Application handlers. [Read more.](/sdk/handlers-applications/)
- Adds events and effects to control provider calendar slot availability.
- Adds support for additional fields on the "Other Events" scheduling tab.
