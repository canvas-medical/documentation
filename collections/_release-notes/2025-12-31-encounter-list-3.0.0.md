- Updates the [Encounter List](https://github.com/Medical-Software-Foundation/canvas/tree/main/extensions/encounter_list) plugin to version canvas-3.0.0, adding support for filtering encounters by the new `SIGNED` note state. We have installed this updated version for all customers that were previously on the canvas-2.0.0 version. If you have installed a customized version - you may need to make the associated changes. Please reference this [PR](https://github.com/Medical-Software-Foundation/canvas/pull/206/files) for guidance.
