Today Canvas Medical is releasing the [Custom Data](https://docs.canvasmedical.com/sdk/custom-data/) SDK feature.

Plugins now have two techniques available to store information within the Canvas EMR durably and securely with minimal setup.
1. Fully normalized relational database schemas via [CustomModels](https://docs.canvasmedical.com/sdk/custom-data-custom-models/), with or without integration to core SDK models.
1. Zero configuration key/value and document storage via [AttributeHubs](https://docs.canvasmedical.com/sdk/custom-data-attribute-hubs/)

To start experimenting, see the [Quick Start](https://docs.canvasmedical.com/sdk/custom-data-quick-start/) guide, and update the `canvas` CLI tool for latest functionality.
