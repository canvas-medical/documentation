Today's release includes the following updates:
<span class="tag-bugfix">bugfix</span>

- Questionnaire commands can now be originated with pre-filled responses — when creating a questionnaire command via a plugin, responses set before calling `.originate()` are applied immediately on creation, removing the need for a separate `.edit()` call. [Read more](/sdk/commands/#questionnaire).
- Fixed note headers not sticking to the top of the page when scrolling on the patient chart.

<span class="tag-sdk">sdk</span>

- Plugins can now use delay/async functionality with SDK effects, enabling deferred or asynchronous execution of effect handlers. [Read more](/sdk/effects/#async-execution).
- Plugins can now define and attach custom fields to [commands](/sdk/commands/), allowing practices to capture additional structured data beyond the built-in command fields.
- Added a new `PATIENT_PAYMENT_PROCESSED` SDK event, which emits when a patient payment is processed. [Read more](/sdk/events/#patient-payments).
