Today's release includes the following updates:

<span class="tag-bugfix">bugfix</span>

- Fixed an issue on the patient portal where the mobile menu stayed open after tapping an item; the drawer now closes automatically on navigation.

<span class="tag-sdk">sdk

- Added new effects for canceling an Appointment or reverting a checked-in Appointment to the booked state. Added new effects for deleting and restoring notes. Added new effect to discharge an inpatient note.
- The notes list now supports a new filter to show deleted notes — by default, deleted notes are hidden.
- Redis and RabbitMQ connections now detect stale or dead pooled connections proactively via health checks, keepalives, and a Celery broker heartbeat, reducing intermittent "Connection reset by peer" errors during business hours.
- Plugins can now mark an existing Observation as entered in error via the new SDK effect: `Observation(observation_id="...").enter_in_error()`.
- N/A — internal admin/API surface (PSK-protected) and a fix that restores intended behavior of an existing endpoint. No customer-visible UI or contract changes.
- The Instruction model is now available in the SDK data module.
- Plugins can now control command button visibility in the patient chart. The new [ConfigureCommandButtons](/sdk/effect-configure-command-buttons/) effect lets plugins hide or disable buttons in chart summary sections and result cards, with changes applied in real time.
