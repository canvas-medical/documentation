Today’s release includes the following updates:

<span class="tag-sdk">sdk</span>
- Adds Facility, ProtocolCurrent, PatientFacilityAddress, and StaffLicense to the SDK data module [Read more.](/sdk/data/)
- Adds `CREATE_PATIENT_PREFERRED_PHARMACIES` effect. [Read more.](/sdk/effect-create-patient-preferred-pharmacies/)
- Enhances the ability to update patients using patient_id, adding support for managing contact points, addresses (line1, line2, city, state, postal code, country, use type), and external identifiers. [Read more.](/sdk/effect-patient/)

<span class="tag-ui">ui</span>
- Adds the ability to create, update, link, and remove authorizations from patient profiles or claims. Updates ensure authorization details remain accurate and aligned with claim activity. [Read more.](https://help.canvasmedical.com/articles/3705672680-managing-authorizations-for-claims)
- Removes the validation preventing previously asessed conditions from being diagnosed within the assess coding gap command.
