Today's release includes the following FHIR API updates for USCDI v3 compliance:

<span class="tag-api">api</span>
- Adds [ServiceRequest](/api/servicerequest/) read and search endpoints
- Adds support to Condition and Observation endpoints for [FHIR granular scopes](https://hl7.org/fhir/smart-app-launch/scopes-and-launch-context.html#finer-grained-resource-constraints-using-search-parameters)
- Adds `basedOn` attribute to [Procedure](/api/procedure/) resource
- Adds `clinical-note` coding to [DocumentReference](/api/documentreference) category for clinical notes
- Adds `specimen` attribute to [Observation](/api/observation/)
- Updates CapabilityStatement so that the deprecated security extension is no longer included, and the `supportedProfile` attribute is present for US Core resources
- Updates [Provenance documentation](/api/provenance/) and adds [Provenance request examples](https://github.com/canvas-medical/canvas-fhir-example-requests)
