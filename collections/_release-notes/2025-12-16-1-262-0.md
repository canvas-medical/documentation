Today's release includes the following FHIR API updates for USCDI v3 compliance:

<span class="tag-api">api</span>
- Added [ServiceRequest](/api/servicerequest/) read and search endpoints
- Added support to Condition and Observation endpoints for [FHIR granular scopes](https://hl7.org/fhir/smart-app-launch/scopes-and-launch-context.html#finer-grained-resource-constraints-using-search-parameters)
- Added `basedOn` attribute to [Procedure](/api/procedure/) resource
- Added `clinical-note` coding to [DocumentReference](/api/documentreference) category for clinical notes
- Added `specimen` attribute to [Observation](/api/observation/)
- Removed deprecated security extension and added `supportedProfile` attribute to resources for CapabilityStatement
- Updated [Provenance documentation](/api/provenance/) and added [Provenance request examples](https://github.com/canvas-medical/canvas-fhir-example-requests)
