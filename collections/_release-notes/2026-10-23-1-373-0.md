Today's release includes the following updates:
<span class="tag-bugfix">bugfix</span>

- Fixed an issue where patient portal login could resolve the wrong account when an email, phone number, or username was shared with another account. The Portal section and account creation now also prevent new duplicates.
- Fixed an issue where side-panel actions such as Refill, Assess, Stop, and Mark as reviewed created a new Chart Review note instead of adding their command to the note the provider was working in. These actions now add to the current note, including when the provider is working in a note application tab.

<span class="tag-sdk">sdk</span>

- No user-facing change. The production image is smaller.
- The canvas-plugins integration tests start home-app more reliably.
- Fixes a flaky end-to-end test for the note filter's Select All staff option.
- Appointment search counts no longer show how many appointments a patient has when that patient is outside your patient groups. The count is now 0, which matches the search results.
- The patient's photo and name show side by side again in the schedule's appointment popover, the reschedule window, and the patient Documents page.
