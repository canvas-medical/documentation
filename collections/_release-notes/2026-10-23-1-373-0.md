Today's release includes the following updates:

<span class="tag-bugfix">bugfix</span>

- Fixed an issue where side-panel actions such as Refill, Assess, Stop, and Mark as reviewed created a new Chart Review note instead of adding their command to the note the provider was working in. These actions now add to the current note, including when the provider is working in a note application tab.
- Fixed an issue where the patient's photo sat on its own row above their name in the schedule's appointment popover, the reschedule modal, and the patient Documents page. The photo and name now show side by side.

<span class="tag-portal">portal</span>

- Fixed an issue where a patient who shared an email address or phone number with another account could not log in to the patient portal.
  - These patients can log in with their username, and the login page reminds them of this when a login fails.
