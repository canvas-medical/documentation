Today's release includes the following updates:

<span class="tag-sdk">sdk</span>

- The following were added to the SDK data module:
  - [PatientAdministrativeDocument](/sdk/data-patient-administrative-document/) exposes the administrative documents on a patient's chart, along with their document coding and a `document_url` for the file itself.
  - [UncategorizedClinicalDocument](/sdk/data-uncategorized-clinical-document/#uncategorizedclinicaldocument) gains a `code` property, so plugins can read the document's coding.
