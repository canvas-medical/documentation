Today's release includes the following updates:

<span class="tag-bugfix">bugfix</span>

- Health Gorilla changed how its lab directory search orders results. Canvas now sends each electronic lab order to the lab's saved Health Gorilla account instead of relying on that search, so orders keep going to the lab they were placed with.
- Fixed an issue where approving or denying a refill, or reviewing a document, from a patient's chart could add the command to another patient's note when you had just reviewed a report for that patient from the panel. The command now always goes to the note of the patient whose chart you're in.

<span class="tag-api">api</span>

- FHIR [Observation create](/api/observation/#create) now checks vitals values against what the Vitals command can show, and returns a 422 with a message that says what to send:
  - **Blood pressure:** systolic/diastolic, such as `122/68`. A trailing `mmHg` is accepted.
  - **Pulse rhythm:** `Regular`, `Irregularly Irregular`, or `Regularly Irregular`.
  - **Other vitals:** a number greater than zero.
