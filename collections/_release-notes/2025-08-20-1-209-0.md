Today's release includes the following updates:

- Introduces a "show in panel" attribute for applications and enables sorting applications by priority.
- Adds `PANEL_SECTIONS_CONFIGURATION` event and `PanelConfiguration` effect, enabling customization of panel (both global and patient) with `PanelPatientSection` and `PanelGlobalSection` components. [Read more.](/guides/customize-panel-buttons/)
- Adds support for creating custom groupings in the medication and condition lists with the patient summary via plugins. 
- Adds `ConfigDict` to the allowed PyDantic imports. [Read more.](/sandboxing-and-allowed-imports/)
