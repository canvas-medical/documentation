Today's release includes the following updates:
<span class="tag-sdk">sdk</span>

- New Order DME command in the note Plan section: order durable medical equipment from a customer-managed formulary or as free text, send it to a supplier, sign, then print or fax the order. Plugins can hook and annotate the DME item and supplier searches.
- The customer logo in the patient portal menu is now centered on desktop, matching the mobile layout. Logos wider than the menu are scaled down to fit rather than extending past the edge.
- Plugins can now record a patient's consent decision (accepted, rejected, and so on) using the new [RECORD_PATIENT_CONSENT](/sdk/effects/) effect. The effect creates or updates the patient's consent for a given consent coding, sets the expiry date from that coding's expiration rule, stores an optional rejection reason, and can attach a signed document as proof.
- Patient charts open faster, especially for patients with many messages. Message cards on the [Patient Timeline](/sdk/effect-patient-timeline/) now update as soon as a message's status changes, without reloading the chart.
- No user-facing change. canvas-plugins integration tests finish faster.
- Single-line text fields on [Commands](/sdk/commands/) stop accepting input at their character limit, so a value can no longer run past the limit and silently block signing.
