Today's release includes the following updates:

<span class="tag-sdk">sdk</span>

- Plugins that read [who last edited a note](/sdk/data-note/#note) now get the staff member who last edited the note or changed its state, such as locking or signing it.
  - The [NOTE_UPDATED](/sdk/events/#note_updated) event names the same staff member as its user.
  - When a plugin [updates a note](/sdk/effect-notes/#update-note), Canvas records the staff member who triggered the plugin as the note's last editor, or Canvas Bot if no one did. The note's provider is set separately.
