- Introduces CLI-based secret management, enabling secrets to be created and updated via the command line. [Read more.](/sdk/secrets/#configuring-secrets-in-the-cli)
- Adds new data module resources including Referral, Referral Reports, Service Provider, and Staff Roles.
- Expands Task Effects 
  - Allows a UUID to be passed to a task, allowing developers to create a task and associate comments upon creation. [Read more.](/sdk/effect-tasks/#adding-a-task)
  - Enables linking of Referrals or Imaging Orders to a task. [Read more.](/sdk/effect-tasks/#linked-object-type)
  - Adds author_id support to change the creator of a task or comment (defaults to canvas-bot if None is passed). [Read more.](/sdk/effect-tasks/#adding-a-comment-to-a-task)
