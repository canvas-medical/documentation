Today's release includes the following updates:

<span class="tag-ui">ui</span>
- Adds a new setting that allows administrators to determine which notes types require signatures. [Read more.](https://canvas-medical.help.usepylon.com/articles/5071031576-configuring-note-signing-requirements)
- Updates signature flow to differentiate between notes that do and do note require signatures. The new flow will be applied to notes created on or after the release date. [Read more.](https://canvas-medical.help.usepylon.com/articles/6989049547-how-to-sign-notes-in-canvas)
- Adds support for multiple signatures.

<span class="tag-sdk">sdk</span>
- Adds effects to lock, sign, unlock, check in, and no show notes. Each supports passing in an [actor](/sdk/events/#event-actor). [Read more.](/sdk/effect-notes/)
