Today's release includes the following updates:
```markdown
<span class="tag-bugfix">bugfix</span>

- Batch claim queue moves are now faster, and a limit has been added to how many claims can be moved in one action.
- Fixed a bug with electronic remittance posting for insurers that have two or more entries in their "Accept remittances from" list.
- Imaging result codes are now normalized when results are ingested, preventing stray or doubled whitespace in a code from causing FHIR Observation and DiagnosticReport reads and searches to fail with a 500 error. Health Gorilla PDF-report attachments are also skipped on ingest, so they no longer create empty lab values.

<span class="tag-sdk">sdk</span>

- Canvas can now stream security audit events — sign-ins, chart access, and clinical data changes — to a customer's SIEM in the OCSF standard, plus a built-in, retained audit-trail view for customers who don't use a SIEM. Exported events carry opaque identifiers only: never patient or provider names, dates of birth, or clinical values.
- The [Review](/sdk/commands/) commands now reject a report that belongs to another patient.
- The [Review](/sdk/commands/) commands now reject a report that belongs to another patient.
- The [Questionnaire](/sdk/commands/#questionnaire) command can now be originated by passing an array of answers, without the need to loop the questions.
- The [Review](/sdk/commands/) commands now reject a report that belongs to another patient.
- The [Remove Allergy](/sdk/commands/#removeallergy) command now rejects an allergy that belongs to another patient, and its `narrative` accepts up to 512 characters.
- The [Resolve Condition](/sdk/commands/#resolvecondition) command now rejects a condition that belongs to another patient.
- The [Stop Medication](/sdk/commands/#stopmedication) command now rejects a medication that belongs to another patient.
- The [Review](/sdk/commands/) commands now reject a report that belongs to another patient.
- Fixed an issue where the [Update Goal](/sdk/commands/#updategoal) command could reference a goal belonging to a different patient, copying that goal's due date and priority onto the current patient's note. Update Goal now confirms the goal belongs to the patient whose chart is being edited and rejects it otherwise.
- The SDK now includes CommandAPI, a base for plugin endpoints to perform command CRUD operations.
```
