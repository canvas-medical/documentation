Today’s release includes the following updates:

<span class="tag-ui">ui</span>
- **Appointment labels**<br/>
Appointments support label functionality, which allow users to [create custom labels](https://help.canvasmedical.com/articles/7708474806-task-claim-labels) to associate with appointments. Configure labels for the Appointment module in Settings > Task labels. Add and manage labels in the when appointment is created or in the appointment card on the Schedule view. Appointments can support up to 3 labels. [Read more](https://help.canvasmedical.com/articles/4617508394-managing-appointments#appointment-labels-37) 
- **Display incoming fax number in Data Integration**<br/>
Added incoming fax number to the document header in Data Integration to provide increased visibility and triage. [Read more](https://help.canvasmedical.com/articles/7371085164-data-integration)

<span class="tag-bugfix">bugfix</span>
- **Only allow active RFV in commands**<br/>
For structured reason for visits, users can only select active reason for visits in the Reason for Visit and Follow Up commands.
- **Bug fix when scheduling appointments with unstructured reason for visits**<br/>
For users that use unstructured reason for visits, they will no longer encounter a non-descriptive error when completing scheduling fields in any order.
