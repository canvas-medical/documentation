Today's release includes the following updates:


<span class="tag-bugfix">bugfix</span>

- Fixed an issue where canceling the Edit provider details modal on a claim kept your changes instead of discarding them. Provider and facility edits are now saved only when you click Update.

<span class="tag-sdk">sdk</span>

- [`canvas validate`](/sdk/canvas_cli/#canvas-validate) and [`canvas install`](/sdk/canvas_cli/#canvas-install) now catch sandbox-incompatible code and Custom Data mistakes before a plugin is deployed. Problems that would previously fail silently at runtime — like tables that never get created or code the sandbox rejects — are now reported up front with clear errors, and `canvas install` stops before uploading when a violation is found. _(requires Canvas CLI 0.177.0 or newer)_
