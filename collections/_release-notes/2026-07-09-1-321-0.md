<span class="tag-sdk">sdk</span>

- Cancelling the Edit provider details modal on a claim now discards your changes instead of keeping them — provider and facility edits are only saved when you click Update.
- `canvas validate` and `canvas install` now catch sandbox-incompatible code and Custom Data mistakes before a plugin is deployed. Problems that would previously fail silently at runtime — like tables that never get created or code the sandbox rejects — are now reported up front with clear errors, and `canvas install` stops before uploading when a violation is found.
