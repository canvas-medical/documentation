Today's release includes the following updates:

<span class="tag-api">api</span>

- Allow updating CareTeams with external members via FHIR. [Read more](/api/careteam/#update)

<span class="tag-sdk">sdk</span>

- File upload related models have been added to the Canvas SDK: [DocumentReference](/sdk/data-document-reference/), [Snapshot/SnapshotImage](/sdk/data-snapshot/), [PatientIdentificationCard](/sdk/data-patient/#patientidentificationcard), and [MessageAttachment.file_url](/sdk/data-patient/#patientidentificationcard)
- Fixed an issue where the note body could display stale content after another user committed changes.
- Fixed an issue where note application tabs where not returning to the note view on close.
- For plugins that handle events where an actor is set — such as action button clicks, application context changes, patient portal interactions, etc — command module methods (originate, commit, edit, delete, review, send, enter-in-error) are now attributed to that user instead of the system bot. Events without an actor continue to be attributed to the system bot.
- Adds the CREATE_CCDA_EXPORT effect that allows creation of CCDA documents for patients. [Read more](/sdk/effect-create-ccda-export/)

<span class="tag-config">config</span>

- Staff images, background images, and logos can now be uploaded directly in Settings.
