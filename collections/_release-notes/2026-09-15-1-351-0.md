Today's release includes the following updates:

<span class="tag-plugins">plugins</span>

- Updates the bundled plugin-runner so the Medication data model in the plugin SDK exposes a new `latest_sig` computed property, returning the medication's most recent sig (prescription instructions) without walking its history.

<span class="tag-sdk">sdk</span>

- Plugin developers can now publish, deploy, configure, and uninstall plugins through the headless Canvas CLI or Studio without needing a separate Control Room account — Canvas signs a short-lived credential on the developer's behalf and proxies the request to Control Room.
- Plugins can now charge a patient's stored card on file via a new SDK effect `ChargeStoredCard`, applying the payment to the patient's account balance or a specific claim. Receipts list the patient as the payer for payments posted directly to a claim.
- Plan- and Procedures-section commands ([Instruct](/sdk/commands/#instruct), [Follow Up](/sdk/commands/#followup), [Goal](/sdk/commands/#goal), [Update Goal](/sdk/commands/#updategoal), [Close Goal](/sdk/commands/#closegoal), [Stop Medication](/sdk/commands/#stopmedication), [Perform](/sdk/commands/#perform), [Immunize](/sdk/commands/#immunize), Task) can now be linked to an Assessment made in the same note through the SDK. No visible change to the note builder yet.
- Internal: Adds the home-app side of the Control Room headless integration (per-instance signing key, git-JWT minting, and deploy + consent proxy endpoints); no user-visible change until an instance is provisioned with a Control Room URL.
