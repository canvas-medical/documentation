Today's release includes the following updates:

<span class="tag-ui">ui</span>

- Claims can now be assigned to a staff member or a team.
  - Pick an owner in the new **Assignee** field on the claim screen.
  - Add the **Assignee** column to a claims queue in Settings to see who owns each claim, and filter or sort by owner, including **Unassigned**.
  - Every owner change, from the claim screen or a plugin, shows in the claim's activity log.

<span class="tag-portal">portal</span>

- Fixed an issue where a telehealth visit in the patient portal lost its **Join** button as soon as its start time passed. A visit now stays under Appointments, with **Join**, until its scheduled end.

<span class="tag-bugfix">bugfix</span>

- Fixed an issue where a command added from the chart to a note with no line selected landed at the top of the note. It now goes below the note's last command.
- Fixed an issue where pasting into a note line right after typing in it could add a command the note didn't show. The pasted command now stays on its line.
