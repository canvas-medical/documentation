Today's release includes the following updates:
<span class="tag-bugfix">bugfix</span>

- In the patient portal, a telehealth appointment now stays in the Appointments tab with its Join button available until the visit's scheduled end time, instead of moving to Past Appointments the moment the start time passes.
- Fixed an issue where Studio's onboarding assistant called a stored secret empty when DrFirst's shared secret and other protected Canvas settings were set. The assistant now reports whether these settings are set without seeing their values.
- Fixed an issue where text pasted into a note line was lost when another save was still in progress. The pasted text is now kept as a Clipboard command until the in-progress save completes.

<span class="tag-sdk">sdk</span>

- Claims can now be assigned to a staff member or a team, just like tasks. Add the new Assignee column to any claims queue to see and manage who owns each claim.
- [Commands](/sdk/commands/) in the revamped note have a cleaner look: they no longer have colored section stripes, labels use sentence case, and inputs have borders. Short choice lists (2–5 options) now show as clickable chips, and uncommitted commands get an "Uncommitted" tag, with Delete moved into the ⋮ menu. A collapsed command fits on one line as its title plus a summary, so Vitals now shows values like BP and pulse. Only applies to refactored notes with the note revamp enabled.
- Plugins can read whether a staff member has verified their identity with ID.me, when, and whether the verified name differed from their staff record, through the new StaffIdentityVerification SDK model.
- Commands added from the chart to a note with no line selected are placed below the note's last command. In the Sections view of the revamped note, clicking a section's command prompt or switching from All to Sections makes that note the target for commands added from the chart.
- Canvas Studio's onboarding agent can add or correct the phone and fax on a staff member who has already signed in to Canvas, so a prescriber's e-prescribing profile can be completed from Studio. Their email stays locked against changes from Studio.
- CI no longer re-runs the Cypress suite after a merge the merge queue already tested; a nightly run on develop keeps full coverage. No change to Canvas itself.
- A vitals entry whose blood pressure is not in systolic/diastolic format, or whose pulse rhythm or measurement site is not one of the listed options, converts to the new note format with those fields left empty. The original values are kept as entered.
