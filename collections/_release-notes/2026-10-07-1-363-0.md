Today's release includes the following updates:

<span class="tag-sdk">sdk</span>

- Plugins can now respond when a claim's balance changes, with the new [`CLAIM_BALANCE_CHANGED`](/sdk/events/#claims) event. Use it to follow payments as they post, or to see when the amount a patient or their insurance owes changes.
  - The event carries the claim's patient and insurance balances from before and after the change.
- Payments a plugin posts with [`ClaimEffect.post_payment`](/sdk/effect-claims/#post-payment) are now saved all at once. If posting fails partway, none of the payment is saved.
- Plugins can now import more in the [sandbox](/sdk/sandboxing-and-allowed-imports/):
  - `secrets`, for secure tokens and comparisons
  - `bisect`, for working with sorted lists
  - `re.I`, and the URL-safe `base64` encode and decode functions
  - Django's `DatabaseError` and the `Length` database function
- Canvas now sends a plugin event only when an installed plugin handles it, which speeds up the requests behind events no plugin uses.
  - Events that no plugin handles no longer appear in the plugin logs.
  - A plugin that is installed, updated, or re-enabled receives its events as soon as it has loaded.
