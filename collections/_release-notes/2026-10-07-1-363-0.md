Today's release includes the following updates:
<span class="tag-sdk">sdk</span>

- Home-app skips sending a plugin event when no installed plugin handles its event type, which removes a plugin runner round trip from those requests. A plugin that is installed, updated, or re-enabled receives its events as soon as the plugin runner has loaded it. Set `PLUGIN_RUNNER_EMIT_ALL_EVENTS=true` to send every event, for example to see all events in the plugin logs.
- New plugin event `CLAIM_BALANCE_CHANGED`: sent once per claim after a change to its balances is saved, with the claim's previous and current patient and coverage balances.
- Payments a plugin posts with `ClaimEffect.post_payment` are now saved all at once. If the posting fails partway, none of it is saved.
- Internal: prod and preview Docker image builds run on Blacksmith runners with persistent layer caching, which makes CI image builds faster and frees GitHub Actions cache space.
- N/A: internal CI change.
