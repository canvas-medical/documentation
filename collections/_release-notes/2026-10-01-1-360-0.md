Today's release includes the following updates:

<span class="tag-bugfix">bugfix</span>

- Fixed an issue where a previously removed external provider could not be added back to a patient's care team. Re-adding any care team member now restores their earlier entry instead of adding a second one, including when a staff member comes back in a different role.
- Improved loading time for notes with many state events in the note footer, such as notes that have been locked and unlocked several times.
- Fixed an issue where users without permission to edit tasks could still open the label picker on a task. The picker is now disabled for them, like the task's other fields.
- Improved accessibility for claim and appointment labels. Screen readers now read each label's name aloud, where they previously read every label as "Emergent".
- Fixed an issue where the protocols list in the chart's right-hand pane stopped working if the patient's protocols failed to load. The pane now shows the error message.

<span class="tag-ui">ui</span>

- The Authorization dropdown in a claim's Billing Provider section now shows the CPT codes each authorization covers.

<span class="tag-sdk">sdk</span>

- Plugins can now read every fax Canvas sends or receives with the new [Fax](/sdk/data-fax/) data model, including the numbers it was sent to and from, its page count, and when it was sent or received.
  - For faxes Canvas sends, plugins can read the delivery status of notes, referrals, imaging orders, lab orders, and integration tasks, including who sent each fax. This includes faxes a plugin sends with the [Fax Note effect](/sdk/effect-notes/#fax-note).
  - [LetterActionEvent](/sdk/data-letter-action-event/) now links to the letter's Fax record.
  - For faxes Canvas receives, plugins can read whether each one was received successfully.
- Plugins can now link [payments, adjustments, and transfers](/sdk/data-posting/) to the [claim line item](/sdk/data-claim/#claimlineitem) they were posted to, in both directions.
  - `billing_line_item` on payments, adjustments, and transfers is deprecated because it can return the wrong charge. Use `claim_line_item.billing_line_item` instead.
