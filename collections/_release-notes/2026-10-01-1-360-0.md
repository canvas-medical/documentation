Today's release includes the following updates:
<span class="tag-bugfix">bugfix</span>

- Fixed an issue where re-adding a previously removed external care team member to a patient's care team would silently fail and the member would not appear on the chart. Re-adding a staff member or external provider now reactivates their earlier care team entry, including when they are added back with a different role.
- Fixed an issue where note state resolution read every state change event, increasing the cost of note queries and note saves. Note state resolution now reads only the latest state change event.
- [NewLineItemPayment](/sdk/data-posting/#newlineitempayment), [NewLineItemAdjustment](/sdk/data-posting/#newlineitemadjustment), and [LineItemTransfer](/sdk/data-posting/#lineitemtransfer) now have a `claim_line_item` field that returns the claim line item the amount was posted to, and the charge is available through `claim_line_item.billing_line_item`. ClaimLineItem now has `newlineitempayments`, `newlineitemadjustments`, and `lineitemtransfers`. `ClaimLineItem.objects.exclude_removed_line_items_without_balances()` no longer raises an error. `billing_line_item` is unchanged but deprecated, because it can return an unrelated charge.

<span class="tag-sdk">sdk</span>

- Plugins can now read the fax delivery status of notes, referrals, imaging orders, lab orders, and integration tasks, including who sent each fax and the number it went to. Letter fax records now include the number the letter was faxed to. Plugins can also read the status Canvas records for each fax it receives.
- Fixed several defects in labels and claims: read-only tasks now correctly disable their label picker, CPT code labels now appear on claims, and claim labels are announced with their own name by screen readers instead of always reading as "Emergent". Search results now show the error text when a search fails rather than breaking the page.
