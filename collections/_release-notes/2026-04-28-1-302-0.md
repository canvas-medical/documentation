Today's release includes the following updates:
<span class="tag-bugfix">bugfix</span>

- Fixed a bug that showed irrelevant refill requests when a staff member is not on any team but the "Me or My Teams" filter is selected.
- Fixed the After Visit Summary not showing the Diagnosed section when it was the only content under Today's Visit.

<span class="tag-api">api</span>

- Added user-level and system-level scopes for FHIR [Questionnaire](/api/questionnaire/) and [QuestionnaireResponse](/api/questionnaireresponse/) as options when creating credentials.

<span class="tag-sdk">sdk</span>

- Added `LabPartnerTestQuestion` and `LabPartnerTestQuestionChoice` to the SDK data module for querying ask-at-order-entry (AOE) questions and choices on lab tests. [Read more](/sdk/data-lab-partner-and-test).
- A mobile-friendly Canvas interface is now available at `https://<instance-name>.canvasmedical.com/companion/`. This is a space for mobile-optimized plugins to be launched from. Companion applications can be scoped to a note, a patient, or global. See [Provider Companion](/sdk/companion/) for more details.
