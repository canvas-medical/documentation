<span class="tag-bugfix">bugfix</span>

- No change for customers. Preview instances can send email again: the SendGrid key was reaching the container under a misspelled variable name, so every outbound email on a preview failed with an unauthorized error from the mail provider, and portal invites produced a link but no message.
- Fixed an issue where team chat intermittently timed out when loading contacts and unread counts. Contacts and unread counts now load reliably.
- Internal CI change with no customer-facing impact.
- Fixed an issue where clicking a command permalink could scroll the linked command out of view as the rest of the note continued to load. The linked command now stays on screen while the remaining note content loads.

<span class="tag-sdk">sdk</span>

- Patient portal notifications for new secure messages, lab results, and statements (email and SMS) now include a magic link that signs the patient straight in and opens the relevant section, with no password step. These links are single-use, and the session they create expires automatically.
- Internal: adds an advisory Vulture dead-code report to home-app's prek pre-push/manual hooks. No customer-facing change.
- Internal: Celery task results older than 90 days are deleted nightly, a batch at a time, so the task results table stops growing.
- The [patient portal](/sdk/patient-portal/) now shows notification badges on portal applications.
- Internal: the home-app mypy pre-push hook runs with docker run instead of docker compose run as one serial invocation, fixing an intermittent git push hang and cold-cache "database is locked" failures, and speeding up local type checks.
- Internal: the Review of Systems questionnaires are now part of the offline content seed, and the remaining Cypress e2e cases for the ROS SDK command are enabled. No user-visible change.
- Clinicians can connect their own Google account from the new Google Calendar page in the account menu, once Google Calendar sync is enabled for the instance. Canvas copies their appointments to a "Canvas (Busy)" calendar in their Google account, and busy events on the Google calendars they select block their availability in Canvas.
- Internal: the knip pre-push hook runs only when home-app JS/TS sources, their configs, the lockfile, or GitHub workflows change.
- No user-facing change. Test-only fix for a timing-dependent failure in a document reference test.
- Internal: CI now fails a PR whose migrations would conflict with develop's latest migrations, before the conflict can reach a deploy.
- Internal: the Build Docker Image workflow no longer runs home-app frontend steps for other services, so building a messaging image works again.
