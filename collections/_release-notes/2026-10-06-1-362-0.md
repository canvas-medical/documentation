Today's release includes the following updates:

<span class="tag-bugfix">bugfix</span>

- Fixed an issue where patients could not create a portal account from their invite link. The Create Account button grayed out and nothing happened. Patients who got stuck can open the same link again to finish.
- The patient portal now shows an error when signing out fails.
- Fixed an issue where team chat intermittently timed out while loading contacts and unread counts. Contacts and unread counts now load reliably.
- Fixed an issue where opening a command permalink could scroll the linked command out of view while the rest of the note loaded. The linked command now stays on screen while the remaining note content loads.

<span class="tag-sdk">sdk</span>

- Plugins can now show [notification badges](/sdk/effect-application-notification-badge/) on `portal_menu_item` applications, next to their label in the patient portal menu.
  - The count is set when the portal loads, from the application's [`compute_notification_badge()`](/sdk/handlers-applications/#notification-badges), which receives the signed-in patient.
  - A badge update sent with `patient_ids` and no `staff_ids` reaches each listed patient in the portal right away.
