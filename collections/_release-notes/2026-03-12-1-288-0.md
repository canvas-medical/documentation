Today's release includes the following updates:

<span class="tag-api">api</span>

- Allow updating Care Teams with external members via FHIR

<span class="tag-sdk">sdk</span>

- DocumentReference, SnapshotImage, PatientIdentificationCard, MessageAttachment, and related models have been added to the Canvas SDK.
- Improved real-time updates for command updates made by the SDK.
- Adds actor to command actions
- Adds CREATE_CCDA_EXPORT effect that allows creation of CCDA documents for patients

<span class="tag-ui">ui</span>

- Staff images, background images, and logos can now be uploaded directly from the admin interface.
