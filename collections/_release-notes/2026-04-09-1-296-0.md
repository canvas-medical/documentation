Today's release includes the following updates:

<span class="tag-bugfix">bugfix</span>

- The practice location "full name" field is now sent in the PracticeLocation.BusinessName field for electronic prescriptions.
- Fixed an issue where fax submission failed with an error when the cover sheet subject, comments, or recipient name contained special characters such as `#`, `&`, `=`, or non-ASCII characters. These fields now properly handle all characters.
- The Axes "AccessLog" view could fail to load due to the volume of records it contained. This has been addressed.

<span class="tag-sdk">sdk</span>

- Adds capability to hide items in note header triple dot dropdown
