Today's release includes the following updates:

<span class="tag-sdk">sdk</span>

- Adds the `assessments` field to the BillingLineItem SDK data model [Read more.](/sdk/data-billing-line-item#billinglineitem)
- Implements the `ClaimLineItemDiagnosisCode` SDK data model [Read more.](/sdk/data-claim#claimlineitemdiagnosiscode)
- Updates the `UpdateClaimLineItem` effect to allow for linking diagnosis codes to a claim line item [Read more.](/sdk/effect-claims#updateclaimlineitem)
- Adds the `NOTE_STATE_CHANGE_EVENT_PRE_CREATE` event [Read more.](/sdk/events)
- Implements the `EventValidationError` effect for blocking the creation of a pre- event (e.g. `NOTE_STATE_CHANGE_EVENT_PRE_CREATE`) [Read more.](/sdk/effect-event-validation-error)
- Implements the `AddClaimComment` effect for adding a new comment to a claim [Read more.](/sdk/effect-claims#addclaimcomment)
- Adds events for creating/updating/deleting Patient Facility Address [Read more.](/sdk/events)

<span class="tag-bugfix">bugfix</span>

- Fixes an issue where appointment cards on the schedule were sometimes cut off.
