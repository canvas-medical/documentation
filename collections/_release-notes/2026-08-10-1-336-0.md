Today's release includes the following updates:

<span class="tag-bugfix">bugfix</span>

- Fixed an issue where verifying a patient's insurance coverage could fail without showing any error, making the check appear to do nothing. Canvas now shows the reason an eligibility check couldn't complete, such as an error returned by the clearinghouse.
- Fixed an issue where a [custom command](/sdk/commands-custom-command/) originated from a plugin's [scheduled task](/sdk/handlers-crontask/) could silently fail to be added to the note when the plugin had been installed while Canvas was already running. A newly installed plugin's custom commands now work right away.
