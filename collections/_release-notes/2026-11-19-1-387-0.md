Today's release includes the following updates:
<span class="tag-bugfix">bugfix</span>

- Fixed an issue where the Data Integration fax number filter did not list every line that has faxes in the selected status, including lines whose faxes have all been processed or junked. With no status selected, it now lists every line that has received a fax. A fax line received both with and without the leading 1 appears once in the fax number filter, and selecting it shows all of that line's faxes.
- Fixed an issue where signed-note PDFs and PDFs attached to Consents created through the FHIR API were stored without a `.pdf` extension and not served as PDFs when downloaded directly. These files are now stored with a `.pdf` extension and served as PDFs. Files stored earlier without an extension are served as PDFs with a `.pdf` filename through FHIR [DocumentReference](/api/documentreference/) and [Consent](/api/consent/) downloads.
- Fixed an issue where `BillingLineItem.objects.find()` did not match billing line items against a value set's CPT and HCPCS Level II codes, so eCQM encounter value sets now find their visits.
- Fixed an issue where lab, imaging, referral, and document reviews could link reports from a different patient. They now only link reports from the patient whose chart they are on.
- Fixed an issue where the home-app container did not start in the canvas-plugins integration test environment when the plugin runner's source directory was empty at startup.

<span class="tag-sdk">sdk</span>

- In the revamped note, the billing footer lists diagnoses in the order they appear in the note and follows drag and drop. Claims rank diagnosis codes in the note's order each time charges are pushed or the note is locked, with a claim comment when the order changes. An ICD-10 code shared by two diagnoses on a note appears once on its claim.
- Plugins can now start, edit, and delete Approve Refill and Deny Refill [commands](/sdk/commands/) in a note, so a refill dashboard plugin can set up a pharmacy refill response without the provider opening each chart. The provider still reviews and sends every response from the command, and a refill request can only be answered once.
- Assess's **Show in problem list** sets one main category: on makes a problem list item, off makes an encounter diagnosis without a domain. Assess has an optional **Category Domain**, available with the box on. Entering an Assess in error restores the categories it changed. Assess cards staged before this release and edited afterwards drop the condition's category domain on record; re-pick it before recording.
- In the revamped note, collapsing an Assess also hides the commands linked to it, and a pill on the Assess shows how many it holds.
- With the note revamp enabled, in-note search now shows a matching command nested under the Assess it is linked to, keeping the Assess in view even when the Assess itself doesn't match. A collapsed Assess that holds a match opens while the search is active and goes back to collapsed when the search is cleared. Reordering is turned off during a search.
- Typing a full name with a space, such as a staff member's first and last name or a team name like "Billing Team", now finds them in the assignee pickers on claims, notes, tasks, and reports. Before, only a single word matched.
