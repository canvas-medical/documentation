Today's release includes the following updates:

<span class="tag-bugfix">bugfix</span>

- Fixed an issue where FHIR API requests that fail command validation — for example, creating a QuestionnaireResponse against a deleted or signed encounter/note — returned an opaque, retryable 502 error. These requests now return a clear 422 error with the specific reason, so API clients recognize them as permanent failures and stop retrying them indefinitely.

<span class="tag-sdk">sdk</span>

- The [PoC Lab Test](/sdk/commands/) SDK command is now Generally Available (GA).
- The [Approve Refill](/sdk/commands/) SDK command is now Generally Available (GA).
- The [Deny Refill](/sdk/commands/) SDK command is now Generally Available (GA).
- The [Reference](/sdk/commands/) SDK command is now Generally Available (GA).
- Plugins can now create, update, and deactivate service providers (provider directory entries), with automatic de-duplication of matching providers. Service providers also gain NPI and Direct address fields.
- Plugins can now access an imaging report's underlying file URL through the [ImagingReport](/sdk/data-imaging-report/) model's `document_url` field, mirroring how DocumentReference already exposes its file.
