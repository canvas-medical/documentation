Today's release includes the following updates:

<span class="tag-bugfix">bugfix</span>

- Fixed error display for unauthenticated users of the Zus CTW widget.
- Labcorp PDF and faxed lab requisitions now default to Patient bill. Previously the bill could route to the practice when no insurance was on file, or be sent with an ambiguous code that Labcorp typically also routed to the practice.

<span class="tag-sdk">sdk</span>

- Plugins can now read the [consent template document](/sdk/data-patient-consent/#accessing-document-files) URL via the `document` field on `PatientConsentCoding` in the SDK.
- A new permission, `activate_deactivate_patient`, now controls who can toggle a patient's active status. Users without this permission will see the "Active patient" checkbox disabled in the Demographics form. The permission is granted by default to the "Profile write" authorization group and all existing staff users.
- Custom [commands](/sdk/commands/) can now be entered in error programmatically via the SDK.
