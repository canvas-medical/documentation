Today's release includes the following updates:

<span class="tag-sdk">sdk</span>

- Adds a new `NOTE_HEADER_DROPDOWN` [action button](/sdk/handlers-action-buttons/) placement, allowing plugins to add custom entries to the note header triple-dot menu.
- Adds [ClaimLineItemModifier](/sdk/data-claim/#claimlineitemmodifier) to the SDK data module, enabling read access to modifiers added to claim line items in revenue. Accessible via `claim_line_item.modifiers.all()` on a [ClaimLineItem](/sdk/data-claim/#claimlineitem).
- Adds [`actor`](/sdk/events/#event-actor) to [`NOTE_STATE_CHANGE_EVENT_PRE_CREATE`](/sdk/events/#notes) events, allowing plugins to identify which user initiated a note state change (e.g., lock, push charges) and conditionally block it based on role.
- [Action buttons](/sdk/handlers-action-buttons/) with the `CHART_PATIENT_HEADER` location now appear on both the chart and profile pages. The `PROFILE_PATIENT_HEADER` location has been removed — plugins using it should switch to `CHART_PATIENT_HEADER`.
- The [Canvas CLI](/sdk/canvas_cli/#update-notifications) now notifies you when a newer version is available on PyPI. This can be disabled with `CANVAS_NO_UPDATE_CHECK=1`.

<span class="tag-ui">ui</span>

- The note header triple-dot menu now includes plugin-provided action buttons below the existing options.
- Fixed the note header triple-dot menu being cut off on small screens, making some options inaccessible.
