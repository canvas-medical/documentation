Today's release includes the following updates:

<span class="tag-api">api</span>
- **Breaking Change:** Updates patient API to return deceasedDateTime by default (when available); falls back to deceasedBoolean if not. 
- Adds support for external care teams in FHIR  [Read more](/api/careteam/)
- Adds support for filtering slots by allowed appointment type in the Slot search endpoint. [Read more.](/api/slot)

<span class="sdk">sdk</span>
- Introduces CLI-based secret management, enabling secrets to be created and updated via the command line.

<span class="ui">ui</span>
- Adds support for adding external providers to patient care teams, allowing patients’ care relationships to be tracked beyond internal team members. [Read more.](https://canvas-medical.help.usepylon.com/articles/5628604712-manage-care-teams#adding-external-care-team-members-12)
- Fixes a bug that prevented users from recording credit card payments without leveraging an integrated credit card processor.
