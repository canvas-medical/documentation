Today's release includes the following updates:
<span class="tag-bugfix">bugfix</span>

- Fixed an issue where a lab report returned from Health Gorilla without a matching Staff NPI did not add the ordering provider to the report's reviewers. The ordering provider is now added as a reviewer even when the report cannot be matched by NPI.
- Fixed an issue where upgrading a plugin kept applications it no longer declares, leaving orphaned or duplicate entries in the provider menu. Upgrading a plugin now removes any applications it no longer declares, so the menu stays in sync with the current plugin definition.
