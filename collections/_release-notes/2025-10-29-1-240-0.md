Today's release includes the following updates:

<span class="tag-sdk">sdk</span>
- Extends task data model to support task metadata. [Read more.](/sdk/data-task/#taskmetadata)
- Adds TaskMetadata effect for creating and updating custom key-value metadata on task records. [Read more.](/sdk/effect-task-metadata)
- Adds FaxNoteEffect effect for faxing notes. [Read more.](/sdk/effect-notes/#fax-note)
- Adds missing prescriber field events for Prescribe, Refill and AdjustPrescription commands.
  - PRESCRIBE__PRESCRIBER__PRE_SEARCH
  - PRESCRIBE__PRESCRIBER__POST_SEARCH
  - REFILL__PRESCRIBER__PRE_SEARCH
  - REFILL__PRESCRIBER__POST_SEARCH
  - ADJUST_PRESCRIPTION__PRESCRIBER__PRE_SEARCH
  - ADJUST_PRESCRIPTION__PRESCRIBER__POST_SEARCH

<span class="tag-ui">ui</span>
- Fixes patient portal menu applications not being highlighted when selected
  - Application's URL is shareable
