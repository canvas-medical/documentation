Today's release includes the following updates:

<span class="tag-sdk">sdk</span>
- Adds timestamp tracking for creation and modification of plugins
- Prevents PrescribeCommand.edit() from incorrectly unsetting medication and type_to_dispense
- Patient Metadata update effect no longer triggers for metadata keys that have not changed
- Adds MedicationHistory to SDK data model
- Adds TypingGuard to allowed imports

<span class="tag-ui">ui</span>

- Updates commands to clear input when not explicitly selecting an option
- Updates schedule view to show both local and the provider's timezone
- Updates Physical Exam command print template to better show selected options
