Today’s release includes the following updates:

- Adds a plugin example of using SimpleAPI to create an API endpoint for patient creation and listening to a patient creation event to keep the patient in sync with a partner system.
- Adds a plugin example of an interactive visualization interface accessible through a "Visualize" button in the patient chart summary vitals section
- Fix a bug where UpdateGoalCommand was not working correctly from the SDK
