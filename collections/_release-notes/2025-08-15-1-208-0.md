Today’s release includes the following updates:
- **Condition modal enhancements**<br/>
  The Condition modal will show related lab and imaging orders. The Assessments timeline in the modal will display Resolved commands in addition to permalinks to the respective command in the note that originated the timeline entry. [Read More](https://canvas-medical.help.usepylon.com/articles/7998893827-managing-conditions).
  
- **Create new task from Global Task Panel**<br/>
   Create tasks from the Global Task Panel with the option to assign tasks to a team, an individual or patient and include a due date, and task labels. [Read more](https://canvas-medical.help.usepylon.com/articles/8460447495-task-management).

- **Update note filtering behavior for new and existing notes**<br />
  With sticky note filters, when a user inserts a command or note that is not part of the current filter view, the filter will be reset. If the user is adding a new note or documenting in a note that is part of the current filter view, the filter will remain applied. [Read more](https://canvas-medical.help.usepylon.com/articles/4791996458-filter-notes-in-patient-timeline#sticky-filter-11).

- **Update Uncategorized Reports and allow for searching**<br/>
  In Data Integration, when a clinical document type is selected, there is optional field to enter a Report Name. In the UI, Uncategorized Reports has been renamed to Medical Documents. Users will now be able to search by Report Name in the Medical Documents. [Read more](https://canvas-medical.help.usepylon.com/articles/7371085164-data-integration).

- **Reschedule, No Show, and Cancel Appointments and Permalink to Note from Appointment Card**<br/>
  For appointments in the schedule view, use the triple dot menu to reschedule, no show, or cancel appointments. Appointments marked as No Show from the appointment card will automatically lock the note. The appointment is also a permalink, so users will automatically be directed to the note on the patient chart. [Read more](https://canvas-medical.help.usepylon.com/articles/4617508394-managing-appointments).

- **Limit editing of Canvas defaults for non-encounter note types**<br/>
  For the following non-encounter note types - Letter, Chart review, Data import, Inpatient visit, and Message - users will not be to change the default settings for “Is Schedulable”, “Is Billable”, or “Is Telehealth”. [Read More](https://help.canvasmedical.com/articles/6785045644-appointment-event-note-types).

- **Inactive care team member cannot be assignees or reviewers**<br/>
  Filter inactive care team members as options in the task assignee or reports reviewers dropdowns.

- **Fix Date in Create and Validate Coding Gap Commands**<br/>
  The create and validate coding gap commands previously did not always populate the current date. Both commands now consistently set the date field to today's date when executed. [Read more](https://help.canvasmedical.com/articles/7998893827-managing-conditions#creating-a-coding-gap-33).

- **Fixed provider display in after visit summary for future appointments.**<br/>
  Accurately displays the provider of the future appointment in AVS.
