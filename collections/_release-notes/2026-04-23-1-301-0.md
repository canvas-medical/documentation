Today's release includes the following updates:
<span class="tag-bugfix">bugfix</span>

- Fixed a race condition where concurrent updates to the same [command](/sdk/commands/) could silently overwrite each other, potentially causing data loss during rapid edits.

<span class="tag-sdk">sdk</span>

- Plugins can now add custom sections to the [patient chart summary](/sdk/layout-effect/#patient-summary), enabling practices to surface domain-specific data alongside the built-in clinical sections.
- Improved the [patient chart timeline](/sdk/effect-patient-timeline/) to enforce that only one note can be open at a time, preventing conflicting edits across multiple open notes.
- Improved page load performance for practices with large staff rosters. Pages that previously slowed down with hundreds of staff members now load significantly faster.
