Today's release includes the following updates:

<span class="tag-sdk">sdk</span>
- Introduces the SDK Lab Review Command for beta testing
- Updates `FamilyHistoryCommand`, `PastSurgicalHistoryCommand`, `MedicationStatementCommand`, `PerformCommand`, and `ImmunizationStatementCommand` command classes to accept both str and Coding types for key fields with custom validation logic to enforce allowed coding systems. [Read more.](/sdk/commands/)
- Expands messaging capabilities in the SDK. [Read more.](/sdk/effect-messages/)
  - Adds `MessageTransmission` events
  - Allows sending messages to staff
  - Allows marking messages as read
- Expands patient summary customization capabilities (annotations and grouping) to coding gaps.
- Adds support for [django's template inheritance](https://docs.djangoproject.com/en/5.2/ref/templates/language/#template-inheritance) when using the [`render_to_string`](/sdk/layout-effect/#custom-html-and-django-templates) util.

<span class="tag-ui">ui</span>
- Adds carry forward option to HPI command.
- Adds fee schedule status to CPT search in vaccine admin.

<span class="tag-bugfix">bugfix</span>
- Fixes various validtion issues with the Questionnaire builder.
