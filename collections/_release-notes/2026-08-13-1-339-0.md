Today's release includes the following updates:

<span class="tag-sdk">sdk</span>

- Plugins can now get from a [DocumentReference](/sdk/data-document-reference/#the-related-object) to the record it was generated from — the originating Lab Report, Invoice, Educational Material, and so on — and from any of those records back to the document reference that carries its file.
- The [Assess command](/sdk/commands/#assess) now checks that the condition it references belongs to the patient whose chart is being written to. Referencing a condition from another patient, or one that doesn't exist, returns a clear validation error instead of being charted silently or failing with a generic error.
- The Assess command's [`narrative`](/sdk/commands/#assess) and the Diagnose command's [`today_assessment`](/sdk/commands/#diagnose) now accept up to 2048 characters.

<span class="tag-ui">ui</span>

- After a Canvas release is deployed, any tab that was already open now offers to reload to the latest version. Previously that tab kept running the older build and could fail with unexplained errors.
