Today's release includes the following updates:

<span class="tag-sdk">sdk</span>

- The [DocumentReference](/sdk/data-document-reference/#documentreference) data model now exposes the record a document was generated from. `content_type` and `object_id` carry the link, and the new `related_object` property resolves it to the SDK model itself — a lab report, imaging report, letter, locked-note PDF, referral report, uncategorized clinical document, educational material, patient administrative document, or invoice. It returns `None` for a document that isn't attached to a record. [Learn more](/sdk/data-document-reference/#the-related-object).
  - You can also go the other way and find every document generated from a given record, which is how you resolve the PDF for one [educational material](/sdk/data-educational-material/#accessing-the-article-pdf).
- The [Assess command](/sdk/commands/#assess) now checks that the condition it references belongs to the patient whose chart is being written to. Referencing a condition from another patient, or one that doesn't exist, returns a clear validation error instead of being charted silently or failing with a generic error.
- The Assess command's `narrative` and the Diagnose command's `today_assessment` now accept up to 2048 characters.

<span class="tag-ui">ui</span>

- When Canvas is updated while you have a tab open, that tab now offers to reload to the latest version. Previously a long-open tab kept running the older build and could fail with unexplained errors.
