Today's release includes the following updates:

<span class="tag-bugfix">bugfix</span>

- Internal: hardened recurring flaky Cypress e2e specs (coding-gap, schedule, token, payment-method, data-explorer, apryse, preset-filters) by re-querying detaching nodes and waiting on settle instead of fixed timeouts. No user-facing changes.
- When Canvas is updated while you have a browser tab open, that tab now shows a banner offering to reload to the latest version. This replaces the unexplained errors that could previously appear when a long-open tab kept running an older build after a deploy.

<span class="tag-plugins">plugins</span>

- The SDK DocumentReference data model now exposes its `related_object`, letting plugin authors follow the generic link from a document reference to its underlying record (lab report, letter, imaging report, note lock, etc.).

<span class="tag-sdk">sdk</span>

- None — internal test-only change with no user-facing impact. Re-enabled three previously-skipped flaky Cypress task specs (panel label filtering; patient close-and-undo; re-open-by-status) and fixed their underlying flake.
- [Assess commands](/sdk/commands/) now verify that a referenced condition belongs to the patient whose chart is being written to. Referencing a condition from another patient (or an unknown condition) now returns a clear validation error instead of silently charting it or failing with a generic error.
- The `today_assessment` field in the SDK diagnose command now enforces a maximum length.
