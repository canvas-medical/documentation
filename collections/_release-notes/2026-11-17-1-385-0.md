Today's release includes the following updates:

<span class="tag-bugfix">bugfix</span>

- Fixed an issue where plugin pages and actions could stall for about 20 seconds and then fail right after a Canvas update or when your instance added capacity. Plugins now respond more reliably through updates.
- Fixed an issue where the report address in report-ready emails wasn't clickable in some mail clients, such as Outlook. The address is now a link.
- Fixed an issue where background tasks could stop running until the instance restarted. Background tasks now run more reliably.
- Fixed an issue where some Health Gorilla lab results left out an abnormal flag, such as H or L. These flags now show on the result.
- Improved performance when saving and signing lab orders, with the largest improvement on instances with a long history.
- Fixed an issue where [`canvas logs --plugin`](/sdk/canvas_cli/#canvas-logs) filtered past logs but streamed every plugin's live logs. The live stream now shows only the plugins you name. _(requires Canvas CLI 1.1.0 or newer)_

<span class="tag-api">api</span>

- FHIR [Medication](/api/medication/) text search (`_text`) now finds medications whether or not a strength has a space before its unit: `500mg` and `500 mg` return the same results, including decimal strengths such as `0.5mg`.
  - A strength written without a space can also return neighboring strengths, so `5mg` can include `25 mg` results.

<span class="tag-sdk">sdk</span>

- [`canvas validate`](/sdk/canvas_cli/#canvas-validate) now warns when a plugin makes a `requests` call with no timeout, and points to the SDK's [Http](/sdk/utils/#making-requests-with-http) helper, which always sets one. _(requires Canvas CLI 1.2.0 or newer)_
