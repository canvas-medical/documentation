Today's release includes the following updates:
<span class="tag-bugfix">bugfix</span>

- Fixed an issue where questionnaire comments were not opening on locked/signed notes for commentable multiple-choice fields.
- Fixed an issue where SDK commands inserted into a note via chart buttons could occasionally vanish from the note body.
- Fixed an issue where SDK commands (prescribe, refill, adjust prescription) could be moved to in-review even when schema validation errors were present.
- Fixed an issue where receiver failures during command commit or enter-in-error were silently swallowed, leaving the command persisted in its new state with downstream data out of sync.
- Fixed an issue where deleting a command via the SDK would not update the note in real time.
- Fixed a bug that prevented Goals from being updated when the start date field has been cleared.
- Fixed instability in the calendar view when creating, editing, or canceling appointments.
- Fixed CCDA exports to return a 400 (bad request) instead of a 500 when a patient does not have a team lead, so callers know to fix the patient record rather than retry the export.

<span class="tag-sdk">sdk</span>

- Updated the diagnostic imaging requisition with enhanced formatting and additional ordering provider information.
- Added a `LabTest` relationship to `LabValue` in the SDK data module, enabling plugins to associate lab values with their corresponding tests.
- Fixed a bug in the Letter author dropdown where customers with more than 350 active staff members couldn't see all providers — the dropdown now searches the full staff directory as you type instead of loading a capped list up front.
- Staff member signatures are now accessible via the SDK data module.
- Fixed two regressions where the non-SDK adjust-prescription review button was incorrectly blocked by an "add your SPI number" prompt for prescribers who already have one, and the appointment results panel was not sorting providers by their configured schedule-column order.
- Plugins can now respond to a new SDK event, `PATIENT_PAYMENT_PROCESSED`, triggered when a patient payment is processed. [Read more](/sdk/events/#patient-payments).
- Internal: CI service-container image pulls now authenticate to Docker Hub, eliminating intermittent rate-limit failures on workflow startup.
- Fixed a Postgres deadlock spike triggered by slow external service calls during lab report ingestion — row locks are no longer held across network I/O, so third-party slowdowns no longer cascade into customer-facing request latency.
- Plugins can now read the instance's configured time zone via `self.environment["INSTALLATION_TIME_ZONE"]` (an IANA name like `America/Los_Angeles`), enabling accurate local-time rendering in plugin output.
- Added Control Room–authenticated API endpoints for centrally installing, upgrading, uninstalling, and configuring managed plugins on a Canvas instance, and masked sensitive plugin secret values in Django admin so they are no longer rendered in the form HTML.
