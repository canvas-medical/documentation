Today's release includes the following updates:
<span class="tag-bugfix">bugfix</span>

- Fixed an issue where a v2 note body change that failed to save was left on screen until the page was reloaded. It now reverts to the note's last saved state.

<span class="tag-sdk">sdk</span>

- Plugin developers can now read `Group` records from the SDK data module, including each group's external ID and its generic link (`content_type` / `object_id`) to the underlying `Team` or `PatientGroup`.
- The [Reference](/sdk/commands/#reference) command is now exposed through the SDK data module, letting plugins read a reference's patient, note, linked diagnostic view, name, and content.
- Plugins can now make chart phone numbers clickable for click-to-dial. A plugin controls — per section (patient, patient contacts, external care team) — whether phone numbers are clickable and whether a click opens the device dialer (`tel:`) or is handled by the plugin, and receives an event when a number is clicked. With no responding plugin, phone numbers render as plain text as they do today. Fax numbers are never clickable.
- The date of birth label now appears next to the patient's name when linking a patient in a Data Integration document.
- Canvas resources now carry `created` and `modified` timestamps, and the [read-only replica](/guides/audit-logging-and-telemetry/#read-only-replica-database)'s SDK data views expose them. Integrations can poll for only the rows that changed since their last run instead of re-reading whole tables, and appointments, patient addresses, and patient contact points support this for the first time.
- A configuration setting keeps commands entered in error out of the note document served over FHIR and the data module. The audit copy linked at the bottom of the note still shows them.
- Conditions without an ICD-10 code now show Resolve and Change Diagnosis (instead of Resolve and Assess) in the chart summary, letting clinicians recode to ICD-10 before assessing.
- Fixed an issue where a stray "null" appeared next to a condition's name when the code was missing.
- Internal: Adds a `set_root_password` management command so cloned instances can reset their database root password to Console's generated value, fixing clone logins that previously only worked with the source instance's password.
- No customer-facing changes. Internal operations tooling for reclaiming database disk space.
- Fixed an issue where phone numbers entered with a leading US country code (e.g. `1-425-208-9647` or `+1 425-208-9647`) dropped the final digit. They now save as the correct 10-digit number.
- Plugin developers can now read coding-gap command events (create, validate, assess, and defer actions on a detected issue) through the SDK data module.
- Fixed an issue where the Type (note type) filter in the revenue claims queue showed an empty dropdown, preventing claims from being filtered by note type. It now lists the available note types again.
