Today's release includes the following updates:

<span class="tag-sdk">sdk</span>

- Adds `CommandMetadata` model to the SDK Data models. [Read more](/sdk/data-command/#commandmetadata)
- Adds `COMMAND_METADATA_CREATED` and `COMMAND_METADATA_UPDATED` events. [Read more](/sdk/events/#command-metadata)
- Adds new `UPSERT_COMMAND_METADATA` effect used to create or update metadata values in a command. [Read more](/sdk/effect-command-metadata/)
- Adds new pharmacy search parameters in search_pharmacies [Read More.](/sdk/utils/#searching-for-pharmacies) :
  - search_term — Full-text search by pharmacy name or organization
  - latitude / longitude — Filter by geographic coordinates
  - zip_code — Filter by zip code
  - state — Filter by state
  - ncpdp_id — Look up a specific pharmacy by its NCPDP identifier
