Today's release includes the following updates:

<span class="tag-sdk">sdk</span>

- Adds new `CommandMetadata` model to the SDK Data models. [Read more](/sdk/data-command/#commandmetadata)
- Adds new `COMMAND_METADATA_CREATED` and `COMMAND_METADATA_UPDATED` events. [Read more](/sdk/events/#command-metadata)
- Adds new `UPSERT_COMMAND_METADATA` effect used to create or update metadata values in a command. [Read more](/sdk/effect-command-metadata/)
- Recently we added some new Document-related models to the Canvas SDK. The pre-signed keys generated for the files related to those objects were incorrect; this has now been addressed.
- Adds new pharmacy search parameters in search_pharmacies [Read more](/sdk/utils/#searching-for-pharmacies) :
  - `specialty` — Filter by pharmacy specialty type
  - `zip_code_prefix` — Filter by zip code
  - `state` — Filter by state code
  - `ncpdp_id` — Look up a specific pharmacy by its NCPDP identifier
