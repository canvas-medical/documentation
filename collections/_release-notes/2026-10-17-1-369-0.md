Today's release includes the following updates:
<span class="tag-bugfix">bugfix</span>

- Custom commands added by plugins now appear on note printouts, faxes, and the PDF saved when a note is locked, including notes that no one opened before printing or locking.

<span class="tag-sdk">sdk</span>

- Plugins now receive created and updated events when notes, referrals, imaging orders, lab orders, and integration tasks are faxed, the same way letter faxes already work. This lets plugins react right away to a fax failure, for example to retry it or alert staff. Fax status updated events, including letter ones, now fire only when the delivery outcome actually changes, so plugins no longer get repeated events while a fax is pending or when the same outcome is reported twice.
- Internal: the Remove Allergy SDK command Cypress spec (6 tests) is no longer skipped and now runs in CI. No user-facing change.
- Plugins can read which staff members a lab report, imaging report, referral report, uncategorized clinical document, or patient administrative document is assigned to for review, and filter documents by assigned reviewer. Plugins can read the team a lab report or imaging report is assigned to, as they already could for referral reports and documents.
- Internal: updates the bundled plugin runner (canvas-plugins) to version 0.250.0.
- Plugins can now read DME products (the DME formulary) and DME orders through the SDK data module, so plugins no longer need hard-coded product IDs when building DME orders.
