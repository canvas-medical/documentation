Today's release includes the following updates:
<span class="tag-sdk">sdk</span>

- Internal: introduces the gated "note v2" refactor — split note-body storage, a GraphQL-first note body API with real-time update subscriptions, atomic command origination/deletion, and forward/backward migration tooling — all behind the `note-refactor:enabled` waffle switch (off by default), so existing note behavior is unchanged on release.
