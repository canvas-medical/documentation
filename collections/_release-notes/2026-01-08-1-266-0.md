Today's release includes the following updates:

<span class="tag-bugfix">bugfix</span>
 - Fixes patient profile additional form fields to properly accept fields from multiple plugins.
 - Fixes a bug so that removing a lab report now correctly marks the associated diagnostic report as entered-in-error.


<span class="tag-sdk">sdk</span>
- Adds support for embedded applications to dynamically resize modal overlays using the MessageChannel API. [Read more.](sdk/layout-effect/#resizing-modals/)
- Implements effects for creating and updating observations via the Canvas SDK [See more.](/sdk/effect-observation/)
- Fixes command "enter in error" effects.

<span class="tag-api">api</span>
- Updates FHIR Encounter status mapping so the new signed note state maps to `finished`.
