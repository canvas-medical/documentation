Today's release includes the following updates:

- Today Canvas Medical is releasing the [Custom Data](https://docs.canvasmedical.com/sdk/custom-data/) SDK feature.
Plugins now have two techniques available to store information within the Canvas EMR durably and securely with minimal setup.1. Fully normalized relational database schemas via [CustomModels](https://docs.canvasmedical.com/sdk/custom-data-custom-models/), with or without integration to core SDK models.1. Zero configuration key/value and document storage via [AttributeHubs](https://docs.canvasmedical.com/sdk/custom-data-attribute-hubs/)
To start experimenting, see the [Quick Start](https://docs.canvasmedical.com/sdk/custom-data-quick-start/) guide, and update the `canvas` CLI tool for latest functionality.
- Adds support for Note Applications to open automatically when a note is viewed, via the new open_by_default() method. [Read more.](/sdk/handlers-applications#opening-by-default)
- Add ability to rename the "Note" tab when charting applications are present.
- Note application tabs have moved from the note body into the sticky note header, keeping them visible while scrolling through long notes.
The assessed/diagnosed conditions summary that previously appeared in the note header has been removed.
