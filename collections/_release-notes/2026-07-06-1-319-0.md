Today's release includes the following updates:


<span class="tag-bugfix">bugfix</span>

- Fixed an issue where opening the refill-request or outstanding-referral worklist across all patients could be slow and temporarily slow down other parts of Canvas for everyone on the instance. These worklists now load quickly.
- Fixed an issue where Approve Refill and Deny Refill could not populate the medication for a refill request whose original prescription wasn't in Canvas (for example, prescriptions migrated in from another EHR), so the refill couldn't be completed. You can now approve or deny these refill requests.
- Appointments rescheduled via a [SchedulingApplication](/sdk/handlers-embedded-applications/#scheduling-applications) handler that opens in a new window no longer get stuck in the Scheduling state (which hid the note's footer buttons).
