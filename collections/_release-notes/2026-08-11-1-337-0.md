Today's release includes the following updates:
<span class="tag-sdk">sdk</span>

- Plugins can now restrict which note types the New Note button offers for a given patient, and hide the button entirely when none are permitted. This affects note creation only — existing notes and the timeline's note type filter still show every note type.
