Today's release includes the following updates:

<span class="tag-bugfix">bugfix</span>

- Fixed an issue where a [Slot](/api/slot/) search returned no availability for a visit type after that visit type was edited in Settings. These searches now return the provider's available time again.

<span class="tag-sdk">sdk</span>

- The plugin runner no longer writes a log line for each handler that runs and each event it handles, so [`canvas logs`](/sdk/canvas_cli/#canvas-logs) and the plugin log viewer show your plugin's own `log` output without two lines per handler in between.
  - Everything on a failure path still logs: a handler that raises an exception, and a handler that returns nothing from `compute()`.
  - Plugin load, reload, unload, and synchronization lines are unchanged.
