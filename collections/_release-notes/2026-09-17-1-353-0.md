Today's release includes the following updates:
<span class="tag-bugfix">bugfix</span>

- Fixed an issue where slot availability could become incorrect after the note types used for filtering were edited and versioned.
- Creating a note through the API now succeeds while an instance is mid-deploy.
- A version 2 note's body now returns each command line with its command uuid, so a plugin reading the note body can resolve the line to its command.

<span class="tag-sdk">sdk</span>

- The Mirth integration engine's administrator API is now reachable only from inside its container. Its public address serves only the integration endpoints that customer instances call.
