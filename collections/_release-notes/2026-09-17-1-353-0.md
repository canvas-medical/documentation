Today's release includes the following updates:

<span class="tag-bugfix">bugfix</span>

- Fixed an issue where a [Slot](/api/slot/) search returned no availability for a visit type after that visit type was edited in Settings. These searches now return the provider's available time again.

<span class="tag-sdk">sdk</span>

- The plugin runner no longer writes a `.compute() completed` line for each handler that runs or a `Responded to Event` line for each event it handles. [`canvas logs`](/sdk/canvas_cli/#canvas-logs) and the plugin log viewer show your plugin's own `log` output without those two lines in between.
