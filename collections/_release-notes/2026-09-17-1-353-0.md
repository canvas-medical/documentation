Today's release includes the following updates:

<span class="tag-bugfix">bugfix</span>

- Fixed an issue where a [Slot](/api/slot/) search returned no availability for a visit type after that visit type was edited in Settings. These searches now return the provider's available time again.

<span class="tag-sdk">sdk</span>

- The plugin runner no longer writes a log line for each handler that runs and each event it handles. [`canvas logs`](/sdk/canvas_cli/#canvas-logs) and the plugin log viewer show your plugin's own `log` output without these two lines in between:

  ```sh
  task_webhook:task_webhook.handlers.event_handlers:Handler.compute() completed (693 ms)
  Responded to Event TASK_CREATED (696 ms)
  ```
