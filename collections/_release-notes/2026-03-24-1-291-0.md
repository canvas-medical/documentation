Today's release includes the following updates:

<span class="tag-bugfix">bugfix</span>

- Fixes an issue where long document labels exceeding 500 characters were causing the refer command to fail when saving.
- For customers that use Candid but not Claim.MD, the payer list would not update on a weekly basis. This has been addressed.
- Fixed intermittent "Save Failed" errors during charting caused by a race condition between command commit and note autosave. Commands that update the note on commit (e.g. Assess, Perform, Diagnose) now fetch only metadata via GET instead of triggering a full PATCH, eliminating the checksum mismatch that caused 409 conflicts. This also removes the note body flash and scroll position jump that occurred when committing or entering-in-error these commands.
- Fixed an issue where protocol recommendations without associated commands could cause the Protocols tab to crash instead of rendering correctly.
- Fixed a bug where the DiagnosticReport and Observations created from a Lab Report were not properly setting LOINC codes
- C-CDA files sent via direct messaging (our DataMotion integration) that contain non-ASCII characters are now handled correctly.
- Fixed an error that could prevent EPCS signing for refill prescriptions.
- Parallel write requests to the CareTeam FHIR endpoint could result in a 500 error due to a race condition. This has been resolved.

<span class="tag-sdk">sdk</span>

- Adds "note" foreign key to LabReview, ReferralReview, and ImagingReview SDK data models.
- Adds the ability to show action buttons on the patient header
- Removes requirement for Google Calendar configuration 
- The monospace fonts have been removed from the print templates and replaced with the serif font.
- Failed prescriptions now show more detail regarding the reason for failure. Additionally, non-ASCII characters in addresses are now transliterated to the nearest ASCII equivalent which will prevent a class of errors from occurring.
- Adds events and effects for patient groups
