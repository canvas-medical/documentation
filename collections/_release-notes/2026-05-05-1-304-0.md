Today's release includes the following updates:
<span class="tag-bugfix">bugfix</span>

- Fixed an issue where SDK commands (prescribe, refill, adjust prescription) could be moved to "in review" even when schema validation errors were present. [Read more](/sdk/commands/).
- Fixed a bug preventing CCDA documents from being ingested when a section uses an OID that differs from what Canvas considers standard for that section.
- Fixed the [ClaimQueue](/sdk/data-claim/#claimqueue) SDK data model to expose the `id` field, enabling plugins to look up claim queues using the queue IDs provided in [CLAIM_QUEUE_MOVED](/sdk/events/#claims) event context.

<span class="tag-sdk">sdk</span>

- Plugins can now make outbound HTTP requests using the new HTTPRequest effect, with support for both synchronous and asynchronous execution.
- SDK plugins now receive DOCUMENT_REVIEWED events for Referral and Uncategorized Document reviews, enabling workflows that respond to these document types. [Read more](/sdk/events/).
- Fixed printing of additional fields on Medication Statement commands so that all configured fields now appear correctly in printed output. [Read more](/sdk/commands/).
