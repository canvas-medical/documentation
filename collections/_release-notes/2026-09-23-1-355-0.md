Today's release includes the following updates:
<span class="tag-sdk">sdk</span>

- Plugins can now generate a patient's portal login link — first-time invite or password reset — and deliver it over their own transport (for example, a practice's own SMS or email provider) instead of Canvas's built-in messaging. A new synchronous SDK utility returns the signed link without sending it.
