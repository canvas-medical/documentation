Today's release includes the following updates:


<span class="tag-bugfix">bugfix</span>

- Fixed an issue where creating a DocumentReference through the FHIR API (POST /DocumentReference) intermittently failed with a 502 error for certain document types.
- Patient charts and individual notes for patients with a large amount of clinical data now load quickly instead of timing out.

<span class="tag-sdk">sdk</span>

- Fixed an issue where a transient network or database error during plugin installation could disable the plugin until it was manually re-enabled. The plugin runner now retries these transient failures instead of disabling the plugin.
