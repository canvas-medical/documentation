Today's release includes the following updates:
<span class="tag-bugfix">bugfix</span>

- Fixed an issue where the SDK's `Appointment.cancel()` and `Appointment.revert()` effects did not validate the appointment's current state or run the same side effects as the equivalent UI actions.
- Fixed a bug where updating a patient coverage's payer after a claim was created did not show the updated coverage as an available option in the claim coverage table; users can now re-add it to refresh the claim with the updated payer information.

<span class="tag-sdk">sdk</span>

- Fixed an issue that prevented plugins from being uninstalled if plugin commands were associated with the plugin.
- Added `group_id` as a new field to the SDK [Team](/sdk/data-team/) data model. This is the same identifier used in the FHIR [Group](/api/group/) endpoint for a team.
