Today's release includes the following updates:

<span class="tag-sdk">sdk</span>

- Facility address updates now automatically cascade to all linked patient facility addresses. When a facility's address fields (line1, line2, city, district, state_code, postal_code, country) are modified, all associated PatientFacilityAddress records are updated asynchronously.
