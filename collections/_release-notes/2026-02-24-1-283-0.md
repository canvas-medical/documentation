Today's release includes the following updates:

<span class="tag-sdk">sdk</span>

- Adds "ndc_dosage" and "ndc_measure" fields to the Fee Schedule and automatically propagates those values to claims charges
- Adds plugin events and data models for LetterActionEvent
- Allows HTTP endpoints created with SimpleAPI to process requests asynchronously.


<span class="tag-bugfix">bugfix</span>

- Fixes an issue that was causing the PatientChartGroup effect to incorrectly sort items
- Fixes an issue where commands could occasionally be missing from the note body when originated via the SDK
