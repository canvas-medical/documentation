Today's release includes the following updates:


<span class="tag-bugfix">bugfix</span>

- Fixed an issue where marking a patient as deceased canceled their upcoming appointments but left the associated claims in the appointment queue as orphaned unsigned notes, with their encounters still open. Now, when a patient is marked as deceased, the claims on those appointments are moved to the trash and the encounters are canceled.
- Fixed an issue where a security lockout could incorrectly block automated requests, such as document printing and faxing, across an entire instance. These requests are no longer affected by the lockout and now process reliably.

<span class="tag-ui">ui</span>

- The Patient Timeline Note Filter previously labeled "Show Deleted Notes" is now "Show Canceled Appointments and Deleted Notes," making it clearer that this toggle reveals canceled appointments as well as deleted notes.
