Today's release includes the following updates:
<span class="tag-bugfix">bugfix</span>

- Fixed an issue where upcoming appointments retained their active claims and encounters after a patient was marked as deceased. All claims and encounters on upcoming appointments are now automatically canceled when a patient is marked as deceased.
- Fixed an issue where requesting a page number beyond the available range on the note metadata list endpoint returned a "not found" error. It now returns an empty result set.

<span class="tag-sdk">sdk</span>

- The [Patient Timeline](/sdk/effect-patient-timeline/) note filter previously labeled "Show Deleted Notes" is now "Show Canceled Appointments and Deleted Notes," making it clearer that this toggle reveals canceled appointments as well as deleted notes.
