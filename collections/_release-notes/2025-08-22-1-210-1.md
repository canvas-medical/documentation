Today's release includes the following updates:

- Adds support for external care teams, allowing patients’ care relationships to be tracked beyond internal care team member. [Read more](pylon link)
- Adds support for external care teams in FHIR  [Read more](/api/careteam/)
- Surfaces visit type specific availability in FHIR Slot endpoint. [Read more.](Nuno to add)
- Adds new FHIR patient extensions for sex and tribal affiliation.
- Expands FHIR Observation resource capabilities with effectivePeriod and component.valueCodeableConcept.
- Introduces CLI-based secret management, enabling secrets to be created and updated via the command line.
- **Breaking Change:** Updates patient API to return deceasedDateTime by default (when available); falls back to deceasedBoolean if not.
