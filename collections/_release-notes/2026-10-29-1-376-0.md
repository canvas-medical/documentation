Today's release includes the following updates:

<span class="tag-ui">ui</span>

- The + button on the Conditions section of the chart summary now adds an Assess command, which can record a new condition or assess one already on the chart.

<span class="tag-bugfix">bugfix</span>

- Fixed an issue where a patient update sent by a plugin cleared the patient's business line, default location, default provider, external identifiers, or previous names when the plugin didn't include them. These now stay unchanged unless the plugin sends them. See [Patient](/sdk/effect-patient/).
- Fixed an issue where a command linked to a Diagnose couldn't be saved or deleted after that Diagnose was deleted.
- Fixed an issue where creating or updating a patient through the FHIR API could remove tribal affiliations recorded on other patients.
