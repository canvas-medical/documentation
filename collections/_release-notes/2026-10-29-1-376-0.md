Today's release includes the following updates:

<span class="tag-ui">ui</span>

- The + button on the Conditions section of the chart summary now adds an Assess command, which can record a new condition or assess one already on the chart. See [Assessing and Updating Conditions](https://help.canvasmedical.com/articles/7989321964-assessing-and-updating-conditions). The Diagnose command is planned for retirement in a future release. See [Important Dates](/product-updates/important-dates/).

<span class="tag-config">config</span>

- New **Denied access to the admin** permission keeps a staff member out of Settings and plugin logs without changing anything else they can do in Canvas. Reach out to Canvas support to set it up for your instance, then assign it to staff in Settings under **Practice: Staff Permissions**. See [User Permissions](https://help.canvasmedical.com/articles/4709841955-user-permissions) and [Removing admin console access](/guides/roles-and-permissions/#removing-admin-console-access).

<span class="tag-bugfix">bugfix</span>

- Fixed an issue where a [patient update sent by a plugin](/sdk/effect-patient/) cleared the patient's business line, default location, default provider, external identifiers, or previous names when the plugin didn't include them. These now stay unchanged unless the plugin sends them.
- Fixed an issue where a command a plugin linked to a Diagnose couldn't be saved or deleted after that Diagnose was deleted.
