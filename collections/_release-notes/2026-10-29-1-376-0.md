Today's release includes the following updates:

<span class="tag-ui">ui</span>

- The + button on the Conditions section of the chart summary now adds an Assess command, which can record a new condition or assess one already on the chart. The Diagnose command is planned for retirement in a future release. See [Important Dates](/product-updates/important-dates/).
- New **Denied access to the admin** permission keeps a staff member out of Settings and plugin logs without changing anything else they can do in Canvas. Add it to a dedicated role in Settings and assign that role to the staff who shouldn't open Settings. See [Removing admin console access](/guides/roles-and-permissions/#removing-admin-console-access).

<span class="tag-bugfix">bugfix</span>

- Fixed an issue where a [patient update sent by a plugin](/sdk/effect-patient/) cleared the patient's business line, default location, default provider, external identifiers, or previous names when the plugin didn't include them. These now stay unchanged unless the plugin sends them.
- Fixed an issue where a command linked to a Diagnose couldn't be saved or deleted after that Diagnose was deleted.
- Fixed an issue where creating or updating a patient through the FHIR API could remove tribal affiliations recorded on other patients.
