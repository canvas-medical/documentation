Today's release includes the following updates:

<span class="tag-bugfix">bugfix</span>

- Fixed an issue where the patient chart's Goals "Active/Closed" filter classified goals incorrectly. The filter now classifies each goal by its most recent update, so a goal that was updated while active and later closed no longer appears under "Active" or sorts by an outdated due date.
- Fixed an issue where installing, updating, or reinstalling a plugin could temporarily block a user's IP address with a site-wide "403 Forbidden" while the plugin reloaded. Requests to plugin endpoints no longer count toward that block.

<span class="tag-sdk">sdk</span>

- The following were added to the SDK data module:
  - [ImagingReport](/sdk/data-imaging/#accessing-the-report-file) gains a `document_url` property, so plugins can read the file attached to an imaging report.
  - [CareTeamMembership](/sdk/data-care-team/#careteammembership) gains a `service_provider` property, so plugins can read a patient's external care team members (e.g. an external PCP) and their contact info with `membership.service_provider.business_fax`. It resolves through the new `organizational_entity` relationship and the new [OrganizationalEntity](/sdk/data-organizational-entity/) data module.
  - [EducationalMaterial](/sdk/data-educational-material/) exposes Educational Material command data — the article's title and abstract, the language it was shared in, and the languages it is available in. The article PDF itself is reached through [DocumentReference](/sdk/data-document-reference/).
- Plugins can now control which items appear in the provider (hamburger) menu via the new [ProviderMenuConfiguration](/sdk/layout-effect/#provider-menu-configuration) effect. For example, a scheduling plugin can hide the native Schedule item so it no longer renders in the menu.
- Running [`canvas validate`](/sdk/canvas_cli/#canvas-validate) no longer reports library-owned handler classes in hidden directories (e.g. `.venv/`) as unreferenced, so plugin authors stop seeing spurious validation warnings. _(requires Canvas CLI 0.191.1 or newer)_
