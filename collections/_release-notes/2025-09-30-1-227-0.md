Today's release includes the following updates:

<span class="tag-api">api</span>
- Removes support for `Prefer: note-append` header in the task update endpoint. All associated comments must be included in the payload for Task updates.[Read more.](/product-updates/important-dates/)
- Removes support for free-text `contact[].relationship[].text` in favor of expanded contact categories. [Read more.](/product-updates/important-dates/)
- Removes support for emergency contact and authorized release-of-information extensions within the FHIR patient endpoint. [Read more.](/product-updates/important-dates/)
- Adds read/search endpoints for FHIR RelatedPerson. [Read more.](/api/relatedperson/)

<span class="tag-ui">ui</span>
- Removes the free text relationship field for patient contacts. Existing records have been migrated to the comments field associated with each contact. Relationships cam now be captured using [preset coded contact categories](https://hl7.org/fhir/R4/valueset-relatedperson-relationshiptype.html) added to each instance. Admins can deactivate these Canvas managed categories if desired. Please reach out to support if assistance is needed.
