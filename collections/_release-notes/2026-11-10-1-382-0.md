Today's release includes the following updates:

<span class="tag-bugfix">bugfix</span>

- Improved performance when loading and working in the patient chart.
- Fixed an issue where a [banner a plugin added or removed](/sdk/effect-banner-alerts/) on a patient's chart, such as after pushing charges, sometimes didn't show until the page was reloaded. Banners now update right away.
- Fixed an issue where e-prescriptions and medication history requests failed when a patient's street address had a line break in it. The address is now sent on one line.
- Fixed an issue where a plugin edit that set [`answers`](/sdk/commands/#questionnaire-answer) on a [Questionnaire](/sdk/commands/#questionnaire), [Review of Systems](/sdk/commands/#review-of-systems), [Physical Exam](/sdk/commands/#physicalexam), or [Structured Assessment](/sdk/commands/#structuredassessment) without naming the questionnaire didn't record them. The answers are now recorded on the questionnaire the command already uses.
