---
title: New setting to rename the Note tab in charting
tags: config
layout: productupdates
date: 2026-04-04
---

The `NOTE_BODY_TAB_LABEL` constance config allows organizations to rename the built-in "Note" tab that appears alongside charting application tabs. The default value is "Note".

This setting helps avoid confusion when a Note Application plugin shares the same name as the built-in Note tab.
