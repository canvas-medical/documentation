Today's release includes the following updates:
<span class="tag-bugfix">bugfix</span>

- Fixed a bug in the appointment scheduling modal where free-text fields — Reason for Visit, Comments, Event Title, and plugin-supplied text fields — would grey out and lose the cursor mid-word when a scheduling plugin was installed, sometimes discarding characters. Text now stays editable while the form refreshes.
- Fixed an issue where self-pay coverages reported an incorrect, stale "Failed" eligibility status. They now report a NOT_APPLICABLE eligibility status.

<span class="tag-sdk">sdk</span>

- Plugins can now add automations to the note body command list. Type `/` in a note body to see them alongside the native commands. A plug icon marks plugin-supplied automations.
- [PrescriptionChangeResponse](/sdk/data-prescription-change-response/) records — the record of an approve or deny to a Surescripts change request — are now available through the SDK data module, letting plugin developers read the response type, status, and detail fields. The associated PrescriptionChangeRequest and PrescriptionChangeRequestCoding models are also now available.
- [CancelPrescription](/sdk/data-cancel-prescription/) events are now available through the SDK data module, letting plugins read the cancelled prescription along with its patient, note, message, and status.
- Prescribers can now sign a prescription without an SPI (Surescripts Prescriber Identifier) number. SPI is required to send a prescription electronically via Surescripts, but no longer blocks review and sign for prescribers who don't transmit through Surescripts (e.g. direct-integration/compounding workflows). Controlled-substance prescribing is unaffected — it remains gated by EPCS enrollment.
- [CancelPrescriptionResponse](/sdk/data-cancel-prescription-response/) records are now available through the SDK data module.
- Plugins can now dock an application in a persistent pane on any edge of the screen — left, right, top, or bottom. The pane stays mounted as you move between pages, can be resized by dragging its handle (or from the keyboard), and remembers the width you set.
