Today's release includes the following updates:

<span class="tag-bugfix">bugfix</span>

- Fixes a bug where incorrect interaction messages were displayed when initiating Refill and AdjustPrescription commands for compound medications from the chart medication list. 

<span class="tag-sdk">sdk</span>

- Added 7 new SDK events for the Data Integration document lifecycle: DOCUMENT_RECEIVED, DOCUMENT_LINKED_TO_PATIENT, DOCUMENT_CATEGORIZED, DOCUMENT_REVIEWER_ASSIGNED, DOCUMENT_FIELDS_UPDATED, DOCUMENT_REVIEWED, and DOCUMENT_DELETED. Plugins can now react to documents arriving, being linked to patients, categorized, assigned to reviewers, having fields updated, being reviewed, or deleted.
