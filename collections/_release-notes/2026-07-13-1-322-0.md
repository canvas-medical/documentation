Today's release includes the following updates:


<span class="tag-bugfix">bugfix</span>

- Fixed an issue where a lab order that included an open-choice Ask-at-Order-Entry (AOE) question could fail with an error. These orders now complete successfully.

<span class="tag-ui">ui</span>

- The annotations shown next to command search results (for example coding-system labels like RxNorm) are now larger, higher-contrast, and rendered in a sans-serif font, making them easier to read.

<span class="tag-sdk">sdk</span>

- Plugins subscribing to the `APPOINTMENT_METADATA_CREATED` and `APPOINTMENT_METADATA_UPDATED` events now receive the associated appointment id and patient id in the [event context](/sdk/events/#appointment-metadata), which was previously empty.
- Fixed an error where creating a billing line item through the [AddBillingLineItem effect](/sdk/effect-billing-line-items/) failed when the charge's name exceeded 255 characters. The line item's description now uses the charge's short name, so these charges save correctly.
