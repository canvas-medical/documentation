This afternoon's release includes the following update:

<span class="tag-config">config</span>
- **Simplify form inactivation logic**<br/>
The `Status` field will be the only field that determines whether a questionnaire is available for users in UI. Users will no longer need to do the additional step of unchecking `Can originate in charting` to prevent forms from showing up in the questionnaire command dropdown. [Read more](https://canvas-medical.help.usepylon.com/articles/7017593857-creating-questionnaires#inactivating-a-questionnaire-41)
