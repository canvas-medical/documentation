Today's release includes the following updates:

<span class="tag-bugfix">bugfix</span>

- Adds token refresh and verification to the patient app to prevent authentication errors when retrieving Lab results.
- Ensures Document Reference's status will be updated to entered-in-error if the original record is junked or entered-in-error or superseded if a later version is saved. 
- Ensures the Full Chart PDF excludes entered-in-error or superseded document attachments
- Ensures that a Follow Up command originated through an Automation grabs the latest version of the Note Type being used. 
- Automatically sets the default Follow Up visit type as the Note Type that is marked “Is default appointment type” in settings
- Clicking outside the application drawer would not close it, unlike other menus and modals in Canvas. We've addressed this inconsistency and now clicking outside the application drawer will close it.
- Allow users to import and export the effective and end date of the Fee Schedule in Settings 
- Same and Next day holds will show as available slots for the current day or any dates in the past. 
- Fixes missing follow-up badge on the patient chart schedule button
- Fixes returning 404 instead of 500 when navigating to a patient that doesn't exist.

<span class="tag-sdk">sdk</span>

- Adds the new data model ClaimMetadata to the Canvas EHR, as well as the corresponding SDK data model. Also adds a method to the ClaimEffect to upsert metadata to a claim.
- Prescriber's DOB was removed from displaying during review state of the Prescribe, Refill, and Adjust Prescription Commands
- Fixes sdk Recommendation to support command and context
