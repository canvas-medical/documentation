Today's release includes the following updates:
<span class="tag-sdk">sdk</span>

- **Dynamic action buttons.** Plugins now have more control over the buttons in the note footer and patient chart, and those buttons stay in sync with live data instead of being rendered once on page load:
  - Refresh a note's or patient's buttons on demand — for example after a command is committed or a note changes state — so their labels, colors, and visibility reflect the latest data, with the [Reload Action Buttons effect](/sdk/effect-reload-action-buttons/).
  - Build footer buttons that move a note through its lifecycle — sign, lock, push charges, discharge, and more — with [Note State Action Buttons](/sdk/handlers-action-buttons/#note-state-action-buttons). Each button appears only when its transition is available, and Canvas ships ready-to-use Sign and Lock buttons.
  - Replace Canvas's default note footer buttons with your own using [Note Footer Configuration](/sdk/effect-note-footer-configuration/).
