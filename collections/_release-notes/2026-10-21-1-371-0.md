Today's release includes the following updates:

<span class="tag-bugfix">bugfix</span>

- Canvas now automatically adds the ControlledSubstance service level and DEA number to a prescriber's Surescripts directory entry once their DrFirst EPCS enrollment becomes active. Previously this had to be done manually, and a missed step caused the prescriber's first controlled-substance prescription to fail silently at the pharmacy.
- Approving a refill request for a controlled substance now transmits. The prescription previously reached the EPCS signing screen and was then rejected by DrFirst, leaving it unsent with no error shown. The name of the staff member who approves a refill on another prescriber's behalf is now included in the response sent to the pharmacy.
- Fixed an intermittent patient portal display problem where every page element could suddenly lose its styling until the page was reloaded, showing oversized icons, plain browser-style buttons, and squeezed plugin pages.
- A brief Redis connection reset during a save no longer reports a saved change as failed. Collect payment, FHIR API writes, note signing, appointment confirmation, and command updates now succeed once the data is saved, and plugin events such as CLAIM_UPDATED still fire.
- A brief Redis connection reset during a save no longer reports a saved change as failed. Collect payment, FHIR API writes, note signing, appointment confirmation, and command updates now succeed once the data is saved, and plugin events such as CLAIM_UPDATED still fire.
- Fixed an issue where v2 notes did not show commands that a plugin chart tab added while it was open, without refreshing the page.

<span class="tag-sdk">sdk</span>

- Revamped notes have a "Search note" box in the header that narrows the note to the commands containing the query, in both the Sections and All views, and highlights the matches, including inside free-text fields. Private notes are only searchable by their author.
- Patient messages can now be assigned to a Team. In the Messages panel, the new Assignee filter (Me, Me or my teams, All, Unassigned, a staff member, or a team) replaces the Recipient filter and defaults to "Me or my teams", and the unread badge now includes messages assigned to your teams. Plugins can set, change, or clear a message's team with the new ASSIGN_MESSAGE_TEAM effect, pass a team_id when creating messages, and react to the new MESSAGE_TEAM_ASSIGNED [event](/sdk/events/).
- Assess has a new "Show in problem list" checkbox. Turn it off to record a diagnosis for this visit only: it is assessed, appears in billing, and can be linked from Plan commands, but stays off the patient's problem list. Turning it back on in a later visit moves the condition onto the problem list. Developers: [AssessCommand](/sdk/commands/#assess) accepts show_in_problem_list.
- Plugins can now read a provider's Google Calendar busy time, Google Calendar connection status (including whether it needs reconnecting), and connected calendars through the SDK data module. Scheduling and booking plugins can use this to account for Google Calendar availability.
- Security improvements across the patient portal and staff admin: stricter consent handling in the portal, safer spreadsheet exports and document rendering, tighter permission checks on CCDA and admin actions, and outbound document and SIEM requests now limited to public destinations.
- Plugins can now see which command types are active on an instance. The SDK's new CommandTypeSetting data model reads this, so a plugin can skip command types an instance has turned off.
- Canvas Studio can now finish setting up its service accounts on instances where its API app was created under the root account. The app gets a new secret during setup.
- Developer-facing only: home-app's end-to-end test framework is upgraded to Cypress 16 and the frontend toolchain to Node 22. No product behavior changes.
