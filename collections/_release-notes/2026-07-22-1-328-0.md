Today's release includes the following updates:
<span class="tag-bugfix">bugfix</span>

- Fixed an issue where removing a claim's insurance to make it self-pay could reprice line items to an outdated fee schedule rate. Self-pay repricing now uses the fee schedule rate in effect on each line item's date of service, so the current rate is applied.
- Fixed an issue where setting a patient's default practice location and default provider through the plugin/SDK Patient effect was silently ignored — the API returned success but the patient's defaults stayed empty. These values are now saved correctly.
- Fixed plugin application drawer icons not rendering correctly the first time the drawer is opened, which briefly showed a broken-image placeholder before loading.

<span class="tag-sdk">sdk</span>

- The lab requisition form no longer displays the "Canvas Medical" header and now presents an electronic signature block with the ordering provider and order date, consistent with the imaging requisition form.
