Today's release includes the following updates:

<span class="tag-api">api</span>
- Fixes a bug where care team membership organization ids were incorrect for external providers.

<span class="tag-ui">ui</span>
- Removed character limit for `background` field in both Diagnose and Assess Condition commands.

<span class="tag-sdk">sdk</span>
- Adds `sum` to the allowed imports. [Read more.](/sdk/sandboxing-and-allowed-imports/)
- Adds `Prefetch` to the django.db and django.db.models.query allowed imports. [Read more.](/sdk/sandboxing-and-allowed-imports/#djangodbmodels)
- Adds `Sum`, `Avg`, `Min`, `Max` to the django.db.models allowed imports. [Read more.](/sdk/sandboxing-and-allowed-imports/#djangodbmodels)
- Adds `Exists`, `OuterRef`, `Subquery` to django.db.models and django.db.models.expressions allowed imports. [Read more.](/sdk/sandboxing-and-allowed-imports/#djangodbmodels)
- Adds events for Imaging Review Command. [Read more.](/sdk/events/#imaging-review-command)
- Adds events for Lab Review Command. [Read more.](/sdk/events/#lab-review-command)
- Adds events for Referral Review Command. [Read more.](/sdk/events/#referral-review-command)
- Adds events for Uncategorized Document Review Command. [Read more.](/sdk/events/#uncategorized-document-review-command)
- Fixes appointment update to no longer create a note state change.
