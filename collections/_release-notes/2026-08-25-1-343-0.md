Today's release includes the following updates:
<span class="tag-bugfix">bugfix</span>

- Admin CSV imports (such as Fee Schedule → Import) no longer fail with a 500 error when confirming an upload on instances running more than one web container. The uploaded file is now staged in shared storage so any container can complete the import.
- Fixed response timeout handling for ClaimMD requests.
- Coverages with the "Patient" payer now show "No eligibility check applies" rather than a failed eligibility check, and no longer send eligibility requests to the clearinghouse.
- Fixed an issue where patient sex stored as Other or Unknown was being incorrectly rendered in printouts and integration payloads.
- Fixed an issue where lab reviews that use "Send via patient app" failed to reopen correctly. Previously, reopening a note that contained one of these signed lab reviews showed "Error loading command" in place of the review.

<span class="tag-sdk">sdk</span>

- Plugins can now read Procedure records (and their CPT codings) through the Canvas SDK data module.
- Family history records are now available through the SDK data module, letting plugin developers read a patient's family history — including the relative's relation and its condition codings.
- Plugins can now read History of Present Illness (HPI) command data through the SDK data module, including both the plain narrative text and the structured narrative_json content.
- Plugin developers can now read coverage eligibility check results — the EligibilityRequest and EligibilityResponse records (status, coverage/request links, payer errors, and parsed X12 response) — through the SDK data module, and can subscribe to eligibility-response events on create, update, and status change (active/inactive/failed).
- The Prescribe, Refill, and Adjust Prescription [commands](/sdk/commands/) now enforce new validations: sig — up to 1000 characters, note_to_pharmacist — up to 210 characters, refills — 0 to 99, days_supply — 0 or greater, quantity_to_dispense — greater than zero (fractional quantities like 0.5 are still valid — half a tablet, 0.5 mL of a suspension — so the bound is exclusive, not a minimum of one).
- The Close Goal command now rejects a goal that belongs to another patient.
- The Prescribe, Refill, and Adjust Prescription [commands](/sdk/commands/) now enforce new validations: sig — up to 1000 characters, note_to_pharmacist — up to 210 characters, refills — 0 to 99, days_supply — 0 or greater, quantity_to_dispense — greater than zero (fractional quantities like 0.5 are still valid — half a tablet, 0.5 mL of a suspension — so the bound is exclusive, not a minimum of one).

- The Update Diagnosis command's `background` and `narrative` are now limited to 2048 characters.
