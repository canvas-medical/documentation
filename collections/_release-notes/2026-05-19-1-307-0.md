Today's release includes the following updates:

<span class="tag-bugfix">bugfix</span>

- Fixed a bug when invoking multiple `CreatePatientExternalIdentifier` effects where only the final invocation was persisted. Multiple `CreatePatientExternalIdentifier` effects now correctly result in multiple patient external identifiers as expected.

<span class="tag-sdk">sdk</span>

- N/A - covered in release notes for 
- Plugin authors can now read `StaffMetadata` and `StaffExternalIdentifier` via the SDK data layer, and write to them with new `StaffMetadata` and `CreateStaffExternalIdentifier` effects — mirroring the existing patient surface.
- Plugin logs can now be filtered by plugin and handler in both the admin UI and the `canvas logs` CLI (`--plugin`, `--handler`).
- If you receive faxes on multiple inbound numbers, you can now optionally filter the fax list in Data Integration to a particular number's received faxes.
- Patient and staff photo URLs may now be obtained via the SDK, removing the need for FHIR API calls to retrieve them.
