Today's release includes the following updates:

<span class="tag-bugfix">bugfix</span>

- [`canvas validate`](/sdk/canvas_cli/#canvas-validate) and [`canvas install`](/sdk/canvas_cli/#canvas-install) now catch two more constructs the [sandbox](/sdk/sandboxing-and-allowed-imports/#forbidden-constructs) rejects: any call to `type()`, not just the three-argument form used for dynamic class creation, and augmented assignment to an attribute (`obj.attr += v`), which is rejected even on classes your plugin defines itself. Both used to pass validation on your machine and then fail once the plugin reached the instance. The error now names the working alternative — `isinstance(x, SomeClass)` or `x.__class__.__name__` instead of `type()`, and `obj.attr = obj.attr + v` instead of `obj.attr += v`. (Requires Canvas CLI 0.198.1 or newer.)
- [`canvas validate`](/sdk/canvas_cli/#canvas-validate) now checks every file in a plugin that happens to live inside a folder named `tests`, `build`, `dist`, `node_modules`, or similar. Those names were previously matched anywhere in the full path to the plugin, so every file was skipped and validation reported success without having examined anything. (Requires Canvas CLI 0.198.1 or newer.)
- Fixed an issue where committing an SDK POC Lab Test did not drop the CPT charge from the test's template onto the encounter.

<span class="tag-sdk">sdk</span>

- The SDK data module now exposes a patient's signed consent documents — plugins can read `PatientConsent.documents` to reach the linked `PatientAdministrativeDocument` records.
- Internal: reduces database load from the protocol evaluation engine by caching `ProtocolSetting` lookups (60s TTL, invalidated on writes) and eagerly joining `ProtocolUpload.active_version` in protocol task querysets. No user-visible behavior change.
- Plugins can now read a goal's update history alongside the goal itself — the SDK data module exposes `UpdateGoal` records, representing the goal updates and closures recorded by the `update_goal` and `close_goal` [commands](/sdk/commands/).
- The [Allergy command's](/sdk/commands/#allergy) `narrative` now accepts up to 512 characters.
- The [Change Medication command](/sdk/commands/#change-medication) now rejects a medication that belongs to another patient.
- The [Family History command's](/sdk/commands/#family-history) `note` now accepts up to 512 characters.
- The [Imaging Order command's](/sdk/commands/#imaging-order) `additional_details` and `comment` now accept up to 1024 characters.
- The [Immunization Statement command's](/sdk/commands/#immunization-statement) `comments` now accepts up to 255 characters.
- The [Medication Statement command's](/sdk/commands/#medication-statement) `sig` now accepts up to 1000 characters.
