Today's release includes the following updates:
<span class="tag-bugfix">bugfix</span>

- Fixed an issue where snoozing plugin ClinicalQualityMeasure protocols did not work correctly.
- Fixed an issue where questionnaires launched by an automation did not honor the questionnaire's current carry-forward setting. Previously an automation could keep carrying answers forward even after carry-forward had been turned off (or a new version was uploaded with it disabled, or the questionnaire was archived), because it used the setting frozen when the automation was created.

<span class="tag-sdk">sdk</span>

- The "Submit a support ticket" link has been removed from the help menu. Support requests are now handled through either the in-app support chat bubble or the [Help Center](https://help.canvasmedical.com).
- Plugins can now subscribe to calendar and calendar-event lifecycle event types (create, update, and delete).
- The Vitals command now includes a "Supplemental Oxygen" vital sign, letting you record whether a patient depends on continuous high-flow, continuous low-flow, or intermittent oxygen. The selection is stored as a coded LOINC value (88658-0 / LL4908-1) so it flows into CCD and FHIR exports rather than plain text.
- When you open a patient's chart, notes now start collapsed instead of one being auto-expanded. A note opens only when you click it, create it, or follow a direct link to it, keeping the chart predictable.
