Today's release includes the following updates:

<span class="tag-bugfix">bugfix</span>

- Fixed an issue where a coverage on a Medicare Advantage, CHIP, automobile, employer, or direct care payer got the plan type Commercial. A coverage now takes its payer's plan type whenever its payer is set, whether in the chart, through the [FHIR Coverage API](/api/coverage/), or by a [plugin](/sdk/effect-coverage/).
  - Coverages added or updated after this release show the correct plan type on claims.
  - Claim coverage tables show plan types by their full names, such as Blue Cross Blue Shield.
  - Plugins can read the new plan types on [coverages](/sdk/data-coverage/#coveragetype).
- Fixed an issue where restoring a canceled appointment from the patient chart could empty its note, leaving only the footer and no place to chart. Restoring the appointment now keeps the note as it was.
