Today's release includes the following updates:
<span class="tag-bugfix">bugfix</span>

- Fixed provider signatures not appearing when previewing or printing letters for staff who have multi-factor authentication enabled.

<span class="tag-config">config</span>

- Admins can now enable a new instance-wide Constance config setting, `HIDE_ASSIGNEE_IN_NOTE_HEADER`, that makes the note header's "Assigned to" control read-only: the note's current assignee or team is still shown but can no longer be changed from the header, and the control is hidden entirely for unassigned notes. Off by default, so existing behavior is unchanged.
