Today's release includes the following updates:
<span class="tag-bugfix">bugfix</span>

- Fixed the Revenue billing-queue sidebar reordering itself when a claim is saved. The queue list now keeps its normal, consistent order during live updates instead of flickering and only settling after a page refresh.
- Outbound faxes to recipients whose names are longer than 100 characters now send successfully — the recipient name is automatically shortened rather than the send being rejected with an error.
- Improved performance when using autocomplete in chart commands.
- Fixed two issues with the calculated BMI in the vitals table: it displayed "Infinity" when a patient had no recorded height (the cell is now blank until a height is recorded), and the "Latest" BMI could combine a height and weight recorded on different dates. The Latest BMI now uses the most recent reading that has both a height and a weight, so it always reflects a single visit.
