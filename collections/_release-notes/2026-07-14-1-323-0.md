Today's release includes the following updates:
<span class="tag-bugfix">bugfix</span>

- Fixed the Revenue billing-queue sidebar reordering itself when a claim is saved. The queue list now stays in its consistent, canonical order on live updates instead of flickering and only settling after a page refresh.
- Outbound faxes to recipients whose names are longer than 100 characters now send successfully — the recipient name is automatically shortened rather than the send being rejected with an error.
- Improved performance when autocompleting commands in the chart.

<span class="tag-sdk">sdk</span>

- Fixed an issue where the vitals table displayed "Infinity" for calculated BMI when a patient had no recorded height. The cell now displays as blank.
