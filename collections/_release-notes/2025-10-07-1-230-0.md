Today's release includes the following updates:

<span class="tag-sdk">sdk</span> <span class="tag-breaking-change">breaking change</span>
- 
- UPDATE_APPOINTMENT / UPDATE_SCHEDULE_EVENT - Now updates existing records without creating a new appointment (without rescheduling)
- RESCHEDULE_APPOINTMENT / RESCHEDULE_SCHEDULE_EVENT - New effect that creates new records with updated values and cancels originals (per existing behavior)

<span class="tag-sdk">sdk</span>

- Adds support for returning multiple effects from SDK Application handlers. [Read more.](/sdk/handlers-applications/)
- Adds events and effects to control provider calendar slot availability.
- Adds support for additional fields on the "Other Events" scheduling tab.
